# Visual QA snapshots

Same-camera screenshot matrices used to audit the heart-failure scene's
rendering quality (captured headlessly via the dev-only `?qa` hook).

- `before/` — baseline before the second full visual overhaul
  (flat basal lid, planar cut, sphere-like LA, particle-cloud congestion,
  segmented story progress).
- `after/` — the same camera presets after the overhaul
  (basal shoulder, curved organic cutaway, seated lobulated LA, sparse
  blood, volumetric congestion haze, leader-line labels, continuous story
  timeline with chapters and a completion state).

Cameras: standard / oblique 45° / cutaway close-up / pulmonary venous view,
each stage at end-diastole (plus ED–ES pairs for Normal and HFrEF), desktop
1440×900 and mobile 390×844 story checks.
