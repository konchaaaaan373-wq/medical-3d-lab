## 1. 何を見せる教材か

閲覧者が **4 つの量を 1 つずつ動かし**、1回拍出量・心拍出量・血圧がどう連動するかを読む、
という教材です。3D の左室・数値・PV ループ・圧波形・字幕は**すべて同じ 1 拍の解**から
派生します（グラフ用の別近似は書いていません）。

操作できるのは次の 4 つだけです。

| 入力 | 単位 | 範囲 | 既定 |
| --- | --- | --- | --- |
| 循環 **stressed volume** | mL | 540 – 980 | 710 |
| 体血管抵抗 SVR | mmHg·s/mL | 0.7 – 1.8 | 1.10（= 1467 dyn·s·cm⁻⁵） |
| 左室収縮末期エラスタンス Ees | mmHg/mL | 0.8 – 4.0 | 2.74 |
| 心拍数 | /min | 50 – 110 | 70 |

## 2. モデルの構造

**7 区画の閉ループ・集中定数モデル**（一つの保存量）。

```
LV --大動脈弁--> 体動脈 --R_sys--> 体静脈 --三尖弁-->
RV --肺動脈弁--> 肺動脈 --R_pulm--> 肺静脈 --> 左房 --僧帽弁--> LV
```

- 心腔は **時変エラスタンス**（Suga & Sagawa）。収縮末期 PV 関係（線形、`Ees·(V−V0)`）と
  非線形の拡張末期 PV 関係（`a·(e^{b·(V−V0)} − 1)` 型）を、正規化した活性化関数で内挿
- 心室の活性化は **double-Hill**（a1=0.269, n1=1.32, a2=0.452, n2=21.9）、位相の約 1/3 で最大
- 心房は後期拡張期の短い sin² のバンプ（位相 0.82 から 0.16 幅）
- 弁は**理想的な一方向抵抗**（逆流ゼロ）
- 積分は 1 拍 240 ステップ、最大 320 拍まで回して**周期定常解**を求める
- 保存量は **circulating stressed volume**（総血液量ではない）。受動区画の容積は
  unstressed 分を除いた stressed volume、心腔は全容積で V0 を別に持つ

**固定パラメータ**（操作不可）:

| 量 | 値 |
| --- | --- |
| 体動脈コンプライアンス | 1.1 mL/mmHg |
| 体静脈コンプライアンス | 120 mL/mmHg |
| 肺動脈 / 肺静脈コンプライアンス | 4.0 / 5.0 mL/mmHg |
| 肺血管抵抗 / 肺静脈抵抗 | 0.08 / 0.03 mmHg·s/mL |
| 弁抵抗（僧帽/大動脈/三尖/肺動脈） | 0.008 / 0.012 / 0.008 / 0.012 |
| 右室 | Ees 0.85, V0 15, EDPVR a=0.35, b=0.02 |
| 左房 | Ees 0.25, V0 15, EDPVR a=2.0, b=0.035 |
| 左室 V0 / EDPVR b | 10 mL / 0.0277 |
| 左室 EDPVR a | 0.4 |

## 4. 介入 2 件（入力を変えるもので、出力への倍率ではありません）

| 介入 | 何を変えるか | 実際の応答 |
| --- | --- | --- |
| 循環充満を増やす | stressed volume +120 mL（他は不変） | SV 67.7→74.2、CO 4.7→5.2、MAP 89→98、LVEDP 7.2→9.7 |
| ドブタミン（収縮力低下例に適用） | Ees ×1.5、SVR ×0.85、**心拍数は据え置き** | SV 53.5→64.4、CO 3.7→4.5、MAP 70.6→73.0、EF 40%→52%、LVEDP 12.5→9.1 |

**心拍数を据え置いている根拠**: Leier CV et al., Circulation 1978;58:466–475
（心筋症性心不全 13 例、2.5–10 µg/kg/min で心拍数に有意な変化なしと報告）。
**公開抄録のみを参照**しており本文は読んでいません。効果量（×1.5 / ×0.85）は
この研究から導いたものではなく、**説明用に選んだ大きさ**です。

**ノルアドレナリンは意図的に入れていません。** 静脈容量を動かせないこのモデルでは
「抵抗だけを上げる薬」に縮約するほかなく、それは教えたいことの逆だと判断しました。

## 5. 収束判定

解が「落ち着いた」と認めるまでに、毎回次を確認します（1 拍 960 ステップで測り直し）。

- **7 区画すべて**の周期残差 ≤ 0.5 mL（solver 自身の終了判定は左室 EDV/ESV だけを見るので不十分）
- 保存量の誤差 ≤ 0.5 mL
- EDV − ESV と大動脈弁通過量の差 ≤ 0.5 mL
- 弁の逆流 **0**（理想弁なので厳密ゼロ）
- 体血管床の圧較差と 平均流量×抵抗 の相対一致 ≤ 2%

満たさなければ `nonconverged` を返し、**数値そのものを返しません**（`metrics: null`）。
操作域の外は**丸めずに拒否**します。宣言域は 865 条件の掃引で決め、域内の最悪値は
周期残差 0.075 mL / SV と弁通過量の差 0.024 mL でした。

## 6. こちらで把握している限界（ここは指摘不要です）

- **反射性調節が一切ない**（圧受容器反射・化学受容器反射・神経体液性・自己調節すべて無し）。
  1 因子ずつ読ませるための設計ですが、人との最大の乖離だと認識しています
- **収縮期の長さが周期の固定比率**。活性化関数が正規化位相で定義されているため、
  心拍数を上げると収縮期と拡張期が同率で短縮します。実際の心臓では収縮期の短縮率のほうが
  小さいので、**このモデルは頻拍で充満時間の不足を過小評価**します。
  実測された帰結として、**宣言域内では CO が心拍数に対して単調増加**します（第 7 節 B-5）
- 応答の**大きさは較正されていません**。主張しているのは**向き**だけです
- 「収縮力低下」プリセットは **Ees を下げただけ**で、HFrEF という症候群ではありません
  （リモデリング・体液貯留・神経体液性亢進・血管系の変化はいずれも無し）
- 平均体静脈圧は **CVP ではありません**（右房がモデルに無い）
- stressed volume は輸液量ではなく、「前負荷」を volume で見せることの誤読リスクは認識しています
- SVR は後負荷の**一成分**にすぎません（動脈コンプライアンス・反射波・弁は入っていない／固定）

## 7. 聞きたいこと

### A. パラメータの現実性（ここが一番知りたい点です）

1. **stressed volume の既定 710 mL** は妥当でしょうか。成人の stressed volume は
   総血液量の 25–30%（≒ 1.2–1.5 L）という記述をよく見ますが、この 7 区画モデルでは
   710 mL で EDV 116 mL・LVEDP 7.2 mmHg・平均肺静脈圧 9.9 mmHg に着地します。
   **区画の取り方が違うだけなのか、それとも数字として低すぎるのか**を知りたいです
2. **SVR 既定 1.10 mmHg·s/mL = 1467 dyn·s·cm⁻⁵**。成人安静時は 800–1200 とされることが
   多く、やや高めに見えます。一方で MAP 89 / CO 4.7 という組み合わせ自体は自然です。
   この不一致は、**右房圧をゼロとみなしている**ことに起因すると考えていますが、
   教材として「SVR」と呼び続けてよいでしょうか
3. **体動脈コンプライアンス 1.1 mL/mmHg** は成人（1.5–2.0 程度とされる）より低めです。
   その結果、既定で脈圧 40 mmHg（107/67）と妥当に見えますが、SVR 上限では 142/105 と
   **脈圧 37 mmHg のまま拡張期だけが大きく上がります**。この挙動は教材として許容範囲でしょうか
4. **Ees 既定 2.74 mmHg/mL** と下限 0.8 / 上限 4.0。正常成人の LV Ees は 2–3 程度という
   理解ですが、**EF 58% が「正常」の代表として低くないか**が気になっています

### B. 操作域の端が、教材として妥当か

5. **HR 110 で CO 5.8・MAP 108** まで上がります。しかも**宣言域の中に、心拍数を上げると
   CO が下がる条件は 1 つもありません**（4 軸 × 心拍数 5/min 刻み・1820 条件を掃引して確認）。
   1回拍出量は確かに下がるのですが、積は必ず増えます。原因は上の「収縮期が周期の固定比率」で、
   **充満時間が足りなくなる転換点が動作域の外**にあるためです。
   その結果、閲覧者が「心拍数を上げれば拍出は増える」を一般則として持ち帰っても、
   **この教材は一度も否定しません**。
   **心拍数の上限を下げるべきか／収縮期を心拍数依存にすべきか／
   注意書きで対処すべきか**、どれが妥当かご意見をください
6. **Ees 0.8 で EF 31%・LVEDP 16.6 mmHg・平均肺静脈圧 17.6 mmHg**。
   肺うっ血の閾値に近づきますが、教材はそれを何も言いません。
   **言うべきでしょうか、それとも「言わない」ことが正しいでしょうか**
7. **充満 980 で LVEDP 12.9・肺静脈圧 16.6**。単独の容量負荷でここまで行くのは妥当でしょうか

### C. 介入について

8. **ドブタミンで心拍数を据え置いた判断**をどう評価されますか。
   1978 年の単一研究（13 例、抄録のみ）を根拠にしており、
   **一般的な β1 作動薬の理解（変時作用あり）と食い違います**。
   教材としては「向きを 1 つに絞る」ために有利ですが、誤りを教えている可能性はありますか
9. **Ees ×1.5 / SVR ×0.85** という大きさは、方向が正しければ許容される類のものでしょうか。
   それとも「大きさを示さない」別の UI にすべきでしょうか
10. **ノルアドレナリンを外した判断**は妥当でしょうか。静脈容量を持たないモデルで
    昇圧薬を扱うことの是非についてご意見をください

### D. 教材としての設計

11. **「前負荷」を stressed volume で見せる**ことの是非。より誤解の少ない提示はありますか
12. 4 つを同時に触れるようにしていますが、**「1 つずつ変える」を守らせる UI 上の仕掛け**として
    何が有効だと思われますか
13. このモデルで**教えてはいけないこと**のうち、上の第 6 節に挙がっていないものはありますか
