# Disease candidates — 臓器別の疾患候補台帳

Last updated: 2026-08-31

新しい疾患シーンの**検討プール**です。ここに載ることは実装の約束ではなく、
「問いとして成立しそうか」のトリアージを済ませたという記録です。

## 候補のパイプライン

```text
本書の候補（トリアージ済み）
      ↓ 有望と判断
src/catalog/scenes.js の PLANNED_SCENES（explorer に方向として表示）
      ↓ adding-a-scene.md の suitability check（7 問）+ proposal template
SCENE_MANIFEST（実装。まず prototype または alpha）
```

- 単位は疾患名ではなく**1 つの理解すべき問い**。1 疾患から複数の問いが
  出ることも、複数疾患が 1 つの問いに畳まれることもあります
- **疾患数は KPI にしません**（[`product-principles.md`](product-principles.md) §9）。
  この台帳が長いのは選択肢を可視化するためで、消化するためではありません
- 着手順は [`grand-design.md`](grand-design.md) §5（深さ > 広がり、
  Gate 0 が新規シーンに優先）が決めます

## 適性の読み方

| 記号 | 意味 |
| --- | --- |
| ◎ | 動的機序が明確で、既存モデルパターン（grand-design §4.4）の再利用か軽い拡張で成立しそう |
| ○ | 有望だが、新パターンの設計か機序の整理が先に要る |
| △ | 2D の模式図で足りる懸念がある。suitability check を通るまで着手しない |
| ★ | `PLANNED_SCENES` に登録済み |

「パターン」列は grand-design §4.4 の略記:
**弾** = エラスタンス閉ループ / **時** = 時定数コンパートメント /
**網** = 抵抗・分岐ネットワーク / **横** = 2 臓器 1 循環 /
**粒** = 粒子状態遷移 / **濾** = 濾過・物質収支（新規予定） /
**帰** = 負帰還ループ（新規予定） / **伝** = 興奮伝播（新規予定）
