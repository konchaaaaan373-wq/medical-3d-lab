## 1. 何を決めたか（7 点）

### 1.1 公開範囲は脳だけ — ゲートの上に「ローンチスコープ」を 1 枚重ねる

初期ローンチが公開するのは `organ: 'brain'` のシーンだけです。
`src/catalog/release.js` に `LAUNCH_SCOPE` を足し、`beta` チャネルの方針を
`launchPublicationProblems`（= スコープの判定 ＋ 従来の `betaPublicationProblems`）にしました。

**消したものはありません。** 心臓・肺・肝臓の解剖と `cardiac-output` は、カタログ・
公開判断記録・レビュー記録・テストをすべて残しています。`betaPublicationProblems('heart-anatomy')`
は今も `[]` を返します——**記録は揃っているが、スコープの外**という状態です。
再公開は `LAUNCH_SCOPE.organs` に 1 語足す編集で、4 件の記録を作り直す作業ではありません。

**スコープは 2 枚目のゲートではありません。** スコープ内であることは何も開けません。
脳のシーンも従来どおり、名指しの一覧・主張の規則・asset gate・公開判断記録を通る必要があります。

production ビルドは、スコープ外のシーンのコード・リンクプレビュー・asset を出力しません
（`npm run verify:site`）。直接 URL（`#/heart-anatomy`・`#/cardiac-output`）は従来の
「準備中」ページになります。

### 1.2 製品名は「3Dモデルラボ」、マークはピンクの脳

名前は [`src/data/brand.js`](../../src/data/brand.js) の 1 か所だけが持つ規則（R-2026-09-30 由来、
`tests/brand.test.js`）はそのままで、中身を差し替えました。

**マークは絵にしました。** ADR 2026-09-30 は「心臓や脳の絵は *medical 3D* と言ってしまう。
それはこの製品がやめたものだ」という理由で絵のロゴを禁じていました。脳だけを扱う製品に
なったので、その理由は成り立たなくなっています。臓器がそのまま製品です。

4 案を作り、16 / 24 / 32 / 48 / 96 / 256 px・明暗両方の地で比較しました
（比較シートは [`../screenshots/brain-launch/brand-candidates.png`](../screenshots/brain-launch/brand-candidates.png)）。

| 案 | 構図 | 評価 |
| --- | --- | --- |
| **A（採用）** | 上から見た左右半球。大脳縦裂をはさむ 2 つの輪郭、中心溝と短い脳溝 | **両半球を表せる唯一の案**。32 px 以上で、脳幹や小脳に頼らず脳と読める。顔・ハート・雲に見えない。正方形に収まる |
| B | 外側面。1 本の線が大脳をなぞりシルビウス裂で終わる | 48 px 以上では最も解剖らしい。左右半球を表せず、16 px で「風船と紐」に寄る |
| C | 斜め上。反対側の半球が縦裂の向こうに覗く | 最も独創的だが、96 px でヘルメット、32 px 以下で豆に見える |
| D | 前面＋脳幹 | 親しみやすいがチューリップに寄り、正中の両脇の脳溝が顔に見える |

**A の残る弱点**: 16 px では「たぶん脳」止まりです（2 つの模様付きの葉）。そのため
タブ用は別の描画にしています——線幅 4、3 つの凹凸、内縁を 4 単位の格子に載せて 16 px で
縦裂が 2 px 抜けるようにした簡略版です。描画は [`src/components/brandIcon.js`](../../src/components/brandIcon.js)
の 1 か所で、PNG・ICO・web manifest はそこから `npm run icons` が作ります。
**商標・類似調査はしていません**（F-285）。

色: ブランドピンク `#E879A6` は細い線として薄い地に置くと 2.6:1 しかないので、
明るい地のマークと文字には深いピンク（マーク `#C94C80`、文字 `#A62F61` = 6.3:1）を使います。

### 1.3 情報設計は 3 つの入口 — 高次脳機能・脳解剖・MRIアトラス

ヘッダーの行き先は [`src/catalog/launch.js`](../../src/catalog/launch.js) の `LAUNCH_AREAS` の 3 つです。
About はメニューとフッターへ移しました。トップページは、実物の脳モデル（操作できる）、
3 つの入口、4 つの学習テーマ（問い）、学び方、根拠と注意、で終わります。

`#/models`・`#/anatomy`・`#/patient` のルートは残しています（共有済みの URL を壊さないため）。
ヘッダーからは出していません。

### 1.4 高次脳機能はサービスの中心に置く。**ゲートは開けない**

これがこの ADR で最も慎重に扱った点です。

- **中心に置く**: ヘッダーの 1 番目、トップの 1 番目の入口、学習テーマの見出し
- **開けない**: `higher-brain-function` は alpha で、医学レビューは未完了です。
  [ADR 2026-09-22](adr-2026-09-22-mechanism-scene-in-beta.md) は機序シーンを 1 本開けるたびに
  その 1 本についての判断と記録を要求しており、**その判断は所有者のものです**。
  実装者が「中心に置け」という指示を「開けろ」と読み替えることはしていません

両方を成り立たせるのが `#/functions`（[`src/app/FunctionsIndex.js`](../../src/app/FunctionsIndex.js)）です。
これは**常に開いている文書**で、学習テーマを**問いとして**並べます
（[`src/data/brainFunctionThemes.js`](../../src/data/brainFunctionThemes.js)）。
「どの構造がどの機能を担うか」は 1 行も書いていません——それを言えるのはモデルと
その根拠資料だけで、モデルはまだ閉じているからです（`tests/mri-atlas-data.test.js` が、
テーマの文言に構造名が現れないことを固定しています）。モデルが開いていないことは、
リンクを灰色にするのではなく**言葉で**伝えます。

**正常機能の解説と、機能障害シミュレーションを分ける検討**は
[`../reviews/2026-11-24-brain-launch-medical-review.md`](../reviews/2026-11-24-brain-launch-medical-review.md) §3
にまとめました。結論だけ書くと：モデルは 1 つで、「経路をたどる（正常）」と
「経路を切る（病変）」は同じ解から出ています。分けて公開するなら、病変の操作を出さない
view を足すのが筋で、**その実装はこの PR には入れていません**（F-286）。先に所有者の判断が要ります。

### 1.5 MRI アトラスは、ラベルボリュームから 3D を作る

新しいシーン `mri-atlas`。設計の芯は 1 行です。

> **3D の面は、断面を塗っているのと同じラベルボリュームから抽出する。**

だから 3D 上の 1 点と断面上の 1 点は、**作り方からして同じ座標**です。
双方向連動は「2 つの仕組みを合わせ込む」ものではなく、「1 つの状態に入力が 2 つある」だけです。

既存の `brain.glb` に MNI 座標を当てはめることは**していません**。あのアトラスは複数の出典の
合成で MNI 空間にありません。当てはめれば「推測を位置合わせとして見せる」ことになります。
両アトラスの間は **9 構造だけ、名称で**つないでいます（`ANATOMY_ATLAS_LINKS`）——
両方が 1 つの塊として同じ名前・同じ左右で描いている構造だけです。視床・扁桃体のように
片方が核に分けているものは、近似せずに外しました。画面にも「名称による対応」と書いています。

データ:

| | 出典 | 取得元 | ライセンス |
| --- | --- | --- | --- |
| T1 / T2 | MNI ICBM 152 2009c Nonlinear Symmetric、1 mm | TemplateFlow | MNI の許諾表示（商用・改変可、表示保持） |
| ラベル | CerebrA（Manera et al. 2020） | TemplateFlow | CC0（出版元の記載。**この環境からは未確認**） |

**公式配布元（mcgill.ca・gin.g-node.org）は、作業環境のネットワーク設定で到達できませんでした。**
同じテンプレートを収載している TemplateFlow から取得し、SHA-256 を
[`scripts/build-mri-atlas.mjs`](../../scripts/build-mri-atlas.mjs) に固定しています。
公式配布物とのバイト比較と、CerebrA の CC0 表示の原典確認は未了です（F-281）。
ライセンス判断は同梱の MNI 表示に基づいており、CC0 には依存していません。

**左右**は、対称テンプレートでは**絵を見ても検証できません**（鏡像でも同じに見えます）。
だから数で確かめています——ビルドが全ラベルの重心の x を測り、アトラス自身の半球表と
一致しなければ止まる。同じ検査がテストと、ブラウザが最初の画素を描く前にも走ります。

### 1.6 NiiVue は採用しない

指示書は「検証し、合理的であれば採用」でした。検証した結果です。

| | NiiVue 0.69.0 | 自前（Canvas 2D ＋ 既存の three） |
| --- | --- | --- |
| ライセンス | BSD-2-Clause（問題なし） | — |
| 配布サイズ | `index.min.js` 2.92 MB / **gzip 859 kB**、依存 7 個 | アトラスのコード 2 チャンク計 **gzip 約 15 kB** |
| WebGL | 自前の WebGL2 コンテキストがもう 1 つ要る | 断面は Canvas 2D。**WebGL が無くても三断面は開く** |
| 左右・座標 | ライブラリ内部 | `src/models/mriAtlas.js`（純 JS）にあり `node --test` で検証できる |
| 3D との連動 | イベントの橋渡しが要る | 1 つの状態を three と canvas が読む |

必要な機能（三断面・スクロール・十字線・拡大・輝度／コントラスト・ラベル重畳と透明度・
方向表示・選択の連動）は、8 ビットの 193×229×193 ボリュームに対しては 2D canvas で足ります。
アプリ全体の three が gzip 172 kB のところへ 859 kB を足す理由がありませんでした。
決め手は 2 つ: **左右の対応を自分たちのテストで握れること**と、
**依存は `three` のみという前提（`CLAUDE.md`）を崩さないこと**です。

NiiVue が要るようになる条件: ボリュームレンダリング、斜断面（MPR）、NIfTI をそのまま
ユーザーが読み込む機能、4D。どれもいまの製品にはありません。

### 1.7 デザインシステムは既存トークンを差し替える

紙とステージのトークン（`--reading-*`・`--bg` ほか）を**その場で**差し替えました。
2 組目を足していないので、既存の全画面が一緒に動いています。新しい面
（`.lab-*`・`.mri-*`）は [`src/styles/lab.css`](../../src/styles/lab.css) と
[`src/styles/atlas-layout.css`](../../src/styles/atlas-layout.css)。

規則: **ピンクは製品の色で、領域の色ではない。** アトラスの配色にピンクの色相は使わず、
MRI 画面でピンクが示すのは選択と現在のタブだけです（`tests/mri-atlas-data.test.js`）。

## 2. 知ったうえで受け入れていること

1. **`mri-atlas` は医学レビューなしで公開します**（マージされれば）。`brain-anatomy` と同じ足場で、
   alpha バッジと「医学レビュー：未完了」が画面に出ます。解剖学者・放射線科医は 1 人も
   見ていません
2. **日本語の構造名 51 個は実装者の訳です。** レビュー項目として列挙しています
3. **左右の独立した解剖学的確認はありません。** 対称テンプレートには目印が無いためです
4. **入力は TemplateFlow 経由で、公式配布物と照合していません**（F-281）
5. **ローンチ時点で、中心に据えた高次脳機能のモデルは閉じています。** 入口ページがそう述べます
6. **規約（`src/data/legal.js`）のサービス名は変えていません。** 既存アカウントへの通知が要る
   変更で、所有者の作業です（F-287）

## 3. 広げ方

- **臓器を足す**: `LAUNCH_SCOPE.organs` に足す。記録が揃っていれば開きます
- **高次脳機能を開く**: レビュー資料 §4 の手順。名指し・判断記録・ADR の 3 点
- **β を終える**: この ADR は `RELEASE_CHANNEL` に触れていません。[`../beta-release.md`](../beta-release.md) のまま
