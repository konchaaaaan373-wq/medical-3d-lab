# Anatomy specs — 臓器別の精密正確性モデル仕様

Last updated: 2026-09-03

各臓器を**どこまで・何を根拠に正確化するか**の仕様台帳です。
[`grand-design.md`](grand-design.md) §4.5（anatomy first / A スケール / pull 型）の
臓器別の実体で、臓器の解剖 upgrade はここの仕様から着手します。

- **A レベルの定義**は grand-design §4.5 が所有（A0 輪郭 / A1 外形実測 /
  A2 機能単位 / A3 脈管・層）
- **何がその構造を要求するか（pull 元）**は
  [`disease-candidates.md`](disease-candidates.md) が所有
- **実測・記録の手順**は [`anatomy-review.md`](anatomy-review.md)（記録）と
  `tests/semantic-anatomy.test.js`（固定）が所有
- 本書が所有するのは**臓器ごとの目標・構造リスト・固定すべき解剖関係・
  受け入れる単純化**

## 仕様の書き方（全臓器共通の規約）

1. **関係で固定し、絶対値は出典とセットで。** テストに落とすのは
   「右主気管支は左より垂直・太く・短い」のような**ランドマーク間の関係**。
   絶対角度・絶対長をコードに書くときは organ builder 側にコメントで出典を
   残す（心臓の 11 関係が手本 — [`anatomy-review.md`](anatomy-review.md) §1）
2. **ローカル座標で定義する**（architecture-rules 規則 2）。部分構造は
   その部分自身の座標系で。左右は**シーンの解剖軸から引く**（規則 5）
3. **教育的標準の一例**であることを崩さない。個体差のある値は
   「成人の教育的標準」であり、モデルの精度を超える桁数を出さない
   （principles §7）
4. **全臓器共通の A1 ミニマム**: 左右・上下・前後が解剖軸と一致 /
   隣接臓器との位置関係が `bodyOverview`（同じビルダーを再利用する全身
   ビュー）で矛盾しない / 臓器間のサイズ比が破綻していない。
   bodyOverview は臓器間整合の**無料の検査台**として使う
5. **A3 は pull がある構造だけ**書く。誰も指さない脈管は仕様にも載せない

## Upgrade の優先順位

pull 元（planned / reviewed 済みシーンの負債）が具体的な順です。

| 順 | 臓器 | 到達目標 | 主な pull 元 |
| --- | --- | --- | --- |
| 1 | 肺・気道（パイロット） | A2 + 部分 A3 | 気胸・肺塞栓・肺炎（planned）、COPD・喘息（reviewed 済みの解剖負債） |
| 2 | 心臓（追補） | A3（冠動脈・刺激伝導系） | 心筋虚血・心房細動（planned） |
| 3 | 腎臓 | A2 統合 | AKI/CKD/ネフローゼ（`renal-filtration` 実装済み）・尿管結石 |
| 4 | 肝臓 | A2（Couinaud） | 門脈圧亢進（reviewed）・肝性脳症・黄疸（候補） |
| 5 | 脳（追補） | A3（血管支配域・脳室系） | 脳梗塞・頭蓋内圧亢進（planned） |
| 6 | 消化管・膵・尿路ほか | pull の到着順 | アカラシア・腸閉塞・糖尿病・BPH ほか |

これ以外の臓器は **A0–A1 のまま凍結**し、pull が来たときにここへ仕様を
書き足してから上げます。

## 1. 肺・気道（lungs / airway）— 目標 A2 + 部分 A3【パイロット】

pull 元: 気胸（胸膜腔・虚脱）、肺塞栓（区域動脈）、肺炎（区域の浸潤）、
無気肺（気管支樹）、COPD・喘息（reviewed 済みだが肺はスタイライズドのまま）。

**A1 — 実測で固定する外形関係**

- 右肺は 3 葉、左肺は 2 葉。右肺は左肺より**短く・幅広く・体積が大きい**
  （高さの差は宣言済みでしたが 2.4% しかなく、両肺のどこを触っても揺らぐ
  程度でした。実際の差は 5〜8% 程度なので広げ、現在は 6.7%）
- 左肺前縁に心切痕、その下に舌区（左肺で中葉に相当する位置づけ）
- 斜裂は両側、水平裂は右のみ
- 肺尖は鎖骨（第 1 肋骨前端）より頭側に出る
- 横隔膜面は右が左より高い（肝臓の分。`SIDE_SHAPE.right.at[1]` が所有。
  以前は両肺を同じ高さに置いていたため、この差は「右肺が短い」ことの副産物に
  すぎませんでした。現在は 7.0%。肺尖はほぼ同じ高さに揃います）
- 肺門: 左肺門は右肺門より高い（`HILUM.elevation` が所有。以前は両側同一の
  オフセットで、差は肺の高さの 1% しかなく、しかも `scale.y` の差と表面投影の
  副産物でした。現在は 5.9%）
- 気管は正中、分岐部（気管分岐角）で左右主気管支に分かれ、
  **右主気管支は左より垂直・太く・短い**（誤嚥が右に多い解剖学的理由。
  教材がこの関係を必ず使う）

**A2 — 名前で指せる単位**

- 肺葉 5（右上・中・下、左上・下）
- 肺区域: 右 S1–S10、左 S1+2, S3–S10（左 S7 欠如を含む教育的標準の区分）。
  疾患シーンは「S6 の浸潤」「舌区の無気肺」を**区域 ID で指定**できること
- 気管支樹: 気管 → 主気管支 → 葉気管支 → 区域気管支。既存の
  `airwayTree.js`（喘息のネットワーク）とこの解剖樹の対応を 1 か所で定義し、
  モデル側の枝とジオメトリ側の枝が食い違わないようにする
  → **`organs/airwayCorrespondence.js` が所有**。記録されているのは主に
  **対応が成立しない範囲**です。対称二分木の第 g 世代は 2^g 枝で、肺の枝数は
  どの階層でも 2 の冪ではないため、第 2 世代（モデル 4 / 解剖 5）以降に
  index↔名前の対応は存在しません。全世代で成立するのは**左右**だけで、
  それは `sideOfModelBranch` が答えます。
  なお heap の `leftChild(0)` = index 1 は**患者の右肺**です（実測: index 1 の
  葉の平均 x は −2.10、`SIDES.right.lateralX` は −1）。`leftChild` は
  二分木の用語であって解剖ではありません——両ファイルが左右を独立に導出して
  いたので、規則 5 に従って 1 か所に固定しました

**A3 — pull がある構造**

- 肺動脈: 主幹 → 左右 → 葉 → 区域枝（気管支に**伴走**する関係を固定）。
  肺塞栓が「どの区域枝を閉じるか」を指すための最小構成
- 胸膜: 臓側・壁側の 2 葉と胸膜腔。気胸が「腔に空気が入る」を描く場所
- 肺静脈は心臓側で実測済み（左房の 4 本のオスティア）なので、
  肺側は区域間走行の**模式**で足りる（単純化として明示）

**受け入れる単純化**: 亜区域以下の分岐 / 気管支動脈 / リンパ路 /
分葉の個体差。いずれも medical-notes に記載。

## 2. 心臓（heart）— 現在 A2、目標 A3（追補）

外形・弁・大血管・肺静脈の 11 関係は実測・テスト固定済み
（[`anatomy-review.md`](anatomy-review.md) §1）。残る仕様は planned 疾患が
指す 2 系統の追補です。

**A3-a 冠動脈（pull: 心筋虚血）**

- 右冠動脈（RCA）は右バルサルバ洞から、左主幹（LMT）は左洞から起始
- LMT → 前下行枝（LAD、前室間溝を心尖へ）+ 回旋枝（LCx、左房室間溝）
- 固定する関係: 起始する洞 / LAD が前室間溝上 / RCA が右房室間溝上 /
  **支配領域**（LAD=前壁・中隔、LCx=側壁、RCA=下壁・右室。優位性は
  右優位の教育的標準 1 例に固定し、model card に明示）
- 虚血シーンは「LAD 領域」を名前で指す。壁運動異常の局在はこの支配領域
  マップだけから導く（描画側で独自に塗らない — single source of truth）

**A3-b 刺激伝導系（pull: 心房細動・伝導ブロック）**

- 洞結節（右房・上大静脈接合部）→ 房室結節（Koch 三角）→ His 束 →
  左右脚 → プルキンエ網
- 固定する関係: 洞結節と房室結節の位置 / 興奮が房室結節**でのみ**心室へ
  渡る（副伝導路は扱わない、と model card に明示）
- 興奮伝播パターン（grand-design §5.2 の新パターン）はこの解剖樹の上を走る

**受け入れる単純化**: 冠静脈系 / 中隔枝・対角枝の個別走行 / 乳頭筋・腱索の
力学（形状のみ）。

## 3. 腎臓（kidney）— 目標 A2 統合

すでに 3 スケールのビルダー（`kidney.js` / `nephron.js` / `glomerulus.js`）が
あるのが強み。仕様の中心は**スケール間の整合**です。

**A1 — 固定する外形関係**

- 左腎は右腎より高い（右は肝臓に押される）
- 腎門は内側を向き、上極は下極よりやや内側（腎軸の傾き）
- 腎門の並び（前から静脈・動脈・腎盂）を教育的標準として固定

**A2 — 名前で指せる単位**

- 皮質 / 髄質（錐体・腎柱）/ 腎杯 → 腎盂 → 尿管の連続
- **糸球体は皮質に、ヘンレループは髄質に降りる**——3 スケールの
  ビルダーを跨いでこの配置関係をテストで固定する（ネフロン模式が
  マクロ断面のどこに埋まっているかを 1 か所で定義）
- ネフロンの区分: 糸球体・近位尿細管・ヘンレ・遠位尿細管・集合管
  （利尿薬シーンが「どの区間か」を指す単位）

**A3 — pull がある構造**

- 腎動脈 → 区域動脈 →（葉間 → 弓状）の主要階層のみ。腎血管性高血圧と
  AKI の腎前性が指す
- 尿管との接続は §12 尿路へ

**受け入れる単純化**: ネフロン数（模式 1 本で代表）/ 傍髄質ネフロンと
皮質ネフロンの区別 / 腎リンパ。

## 4. 肝臓（liver）— 目標 A2（Couinaud）

pull 元: 門脈圧亢進（reviewed。門脈網は `portalVasculature.js` に実装済み）、
肝性脳症・黄疸・初回通過効果（候補）。

**A1 — 固定する外形関係**

- 右葉 > 左葉。横隔膜面は凸、臓側面に胃・腎・結腸の圧痕
- 胆嚢は右葉臓側面（胆嚢窩）、肝鎌状間膜は**形態上の**左右境界
- **機能的左右境界は Cantlie 線（胆嚢窩–下大静脈線、中肝静脈の面）**であり
  鎌状間膜ではない——形態境界と機能境界のずれ自体が教材価値を持つので、
  両方を持ち関係をテストで固定する

**A2 — 名前で指せる単位**

- Couinaud 区域 S1–S8。門脈圧亢進・肝切除の文脈が指す単位
- **門脈系は区域の中心を、肝静脈は区域の間を走る**（互い違いの関係）。
  既存の `portalVasculature.js` の枝をこの区域定義に対応付け、
  モデルの枝とジオメトリの区域が 1 対 1 になるようにする
- 肝門（門脈・肝動脈・胆管の三つ組）と下大静脈への 3 肝静脈

**A3 — pull がある構造**

- 胆道: 左右肝管 → 総肝管 →（胆嚢管合流）→ 総胆管。黄疸の 3 型と
  総胆管結石が指す
- 類洞・小葉レベルは**模式 1 小葉で代表**（門脈域 → 類洞 → 中心静脈の
  向きだけ固定）

**受け入れる単純化**: S1（尾状葉）の特殊な静脈還流 / 肝動脈の変異 /
区域境界の個体差。

## 5. 脳（brain）— 現在 A2（アトラス）、目標 A3（追補）

脳回・脳溝・深部構造は brain-anatomy シーンで到達済み。残る仕様は
planned 疾患が指す 2 系統です。

**A3-a 動脈支配域（pull: 脳梗塞）**

- Willis 輪（内頸 → 前・中大脳動脈、椎骨脳底 → 後大脳動脈、前後交通動脈）
- 支配域: ACA=内側前頭〜頭頂、MCA=外側面の大部分＋深部（レンズ核線条体動脈）、
  PCA=後頭・視覚野。**既存アトラスの脳回 ID との対応表**として定義し、
  「MCA 領域」= 脳回集合、が 1 か所で決まるようにする
- 梗塞シーンは領域 ID を指す。症状（片麻痺・失語）は領域 → 機能野の
  対応から導き、model card にその単純化を明示

**A3-b 脳室系と髄液路（pull: 頭蓋内圧亢進・水頭症）**

- 側脳室 → モンロー孔 → 第三脳室 → 中脳水道 → 第四脳室 → ルシュカ・
  マジャンディ孔 → クモ膜下腔。**狭窄しやすい点（モンロー孔・中脳水道）**を
  名前で指せること（閉塞部位ごとの水頭症パターンが教材になる）
- 頭蓋内の 3 区画（脳実質・血液・髄液）の体積勘定は ICP モデル側が所有し、
  ジオメトリは区画の**場所**だけを所有する（モデルとジオメトリの分担を
  明示）

**受け入れる単純化**: 灌流の個体差（交通動脈の発達差）/ 静脈洞系 /
細動脈レベルの吻合。

## 6. 消化管（esophagus / stomach / small-intestine / colon）— 目標 A1–A2

**食道（pull: アカラシア・静脈瘤・GERD）**

- 3 生理的狭窄（輪状咽頭部 / 気管分岐・大動脈交差部 / 横隔膜貫通部）を
  名前で指せること（異物・癌好発部位の教材にそのまま使う）
- 下部食道括約筋（LES）を独立した単位に——アカラシアと GERD が
  互いに逆向きに指す構造
- 静脈瘤 pull が来たら粘膜下静脈叢と門脈系への接続（§4 と共有）

**胃（pull: 幽門狭窄・ダンピング）**

- 噴門・胃底・胃体・幽門前庭・幽門、大彎・小彎、His 角
- 蠕動波は胃体 → 幽門へ（既存 `upperGi` の波と対応付ける）

**小腸（pull: 腸閉塞・腸間膜虚血）**

- 十二指腸 C 字と**ファーター乳頭**（総胆管・主膵管の合流開口。
  §4・§7 と共有する 1 点）
- 空腸/回腸の差（壁厚・血管アーケード）は模式でよいが、
  **腸間膜と上腸間膜動脈（SMA）の扇形**は虚血 pull が指すので単位化

**大腸（pull: 捻転・憩室）**

- 盲腸〜S 状結腸の枠、結腸ヒモ・ハウストラ（憩室の好発が**ヒモ間**で
  ある関係）、S 状結腸の可動性（捻転の解剖学的前提）

**受け入れる単純化**: 腸管の実長（縮尺明示）/ 微細絨毛 / 腸内容。

## 7. 膵臓（pancreas）— 目標 A1–A2

pull 元: 糖尿病（planned）、急性膵炎・膵管閉塞（候補）。

- 頭部・鉤状突起・体部・尾部。**鉤状突起が上腸間膜動静脈を後ろから抱える**
  関係（膵頭部癌・膵炎の画像解剖の基本）
- 主膵管が尾 → 頭へ走り**ファーター乳頭で総胆管と合流**（§4・§6 と共有。
  胆石性膵炎の解剖学的前提）
- 内分泌（島）と外分泌（腺房 → 導管）は既存シーンの模式を維持し、
  ジオメトリ上の分布は「尾部に島がやや多い」程度に留める

**受け入れる単純化**: 副膵管 / 島の実分布 / 血管支配の詳細。

## 8. 甲状腺・副腎（thyroid / adrenal）— 目標 A1

内分泌の pull（糖尿病・機能亢進症）は主に**負帰還モデル側**の仕事で、
ジオメトリ要求は薄い。A1 の外形関係のみ固定します。

- 甲状腺: 両葉 + 峡部、気管前面・輪状軟骨直下。濾胞構造は既存の模式を維持
- 副腎: 腎上極に接し、**右は三角形（肝の下）・左は半月形**の左右差。
  皮質 / 髄質の 2 層（既存シーンが既に使う単位）を維持

**受け入れる単純化**: 反回神経・上皮小体との位置関係（甲状腺手術の解剖は
このアプリの主題ではない、と明示）。

## 9. 脾臓（spleen）— 目標 A1

- 左上腹部、第 9–11 肋骨の高さで横隔膜に接する
- 脾門（動静脈の出入り。**脾静脈 → 門脈**の接続は門脈網と共有済み）
- 赤脾髄 / 白脾髄は既存の濾過シーンの模式を維持

## 10. 骨・骨格筋（bone / skeletal-muscle）— 目標 A1

- 骨: 皮質骨 / 海綿骨（骨梁）、骨端 / 骨幹端 / 骨幹の区分。
  骨粗鬆症（planned）が指すのは**骨梁の網目**なので、リモデリング面の
  既存模式に骨梁スケールを 1 段追加するのが A2 相当の仕事
- 筋: 筋腹 / 腱の区分と、筋線維の走行方向（収縮方向と一致させる）。
  重症筋無力症 pull が来たら神経筋接合部を**模式 1 点**で追加

---

## 11. 生殖器（uterus / prostate）— 目標 A1–A2

- 子宮: 前傾・前屈の標準位、内膜 / 筋層 / 漿膜の 3 層（既存の周期シーンが
  内膜厚を使う）、卵管・卵巣の位置
- 前立腺: **尿道を全周性に囲む**関係（既存シーンの中核）に加え、
  BPH pull（planned）で**移行域 / 辺縁域のゾーン解剖**を A2 単位に——
  「BPH は移行域、癌は辺縁域」がこの臓器の教材価値の中心

---

## 12. 尿路（ureter / bladder）— 目標 A2（結石 pull）

- 尿管の**3 生理的狭窄**（腎盂尿管移行部 / 総腸骨動脈交差部 / 膀胱壁内部）を
  名前で指せること——尿管結石（planned）の嵌頓部位はこの 3 点で、
  シーンの主張がそのまま載る
- 膀胱三角（両尿管口 + 内尿道口）と、壁内尿管の斜走（逆流防止弁の機構。
  膀胱尿管逆流の候補が指す）
- 排尿筋 / 括約筋は排尿反射の候補が来たときに単位化

## 13. 全身ビュー（whole-body）— 整合の検査台

`bodyOverview` は独自ジオメトリを持たず**各臓器ビルダーを再利用する**ので、
臓器間の A1 整合（位置・サイズ比・向き）をここで実測します。

- 固定する関係の例: 肝は右上腹部で右横隔膜を押し上げる / 脾は左後外側 /
  左腎 > 右腎の高さ / 心尖は左下前方 / 気管分岐部と大動脈弓の高さ関係
- 臓器を upgrade したら bodyOverview での見え方を必ず実レンダリングで確認
  （1 臓器のローカルな改善が全身ビューの整合を壊すのが典型的な回帰）

## 未決の 2 件（判断待ち）

仕様として「やる／やらない」が決まっていない項目です。**黙って先送りにせず**
ここに書いておきます。

### 1. 肝臓の血管樹を 2 本から 1 本にするか

肝臓の血管は 2 つのビルダーが作っており、**4 構造が重複**しています——門脈・
門脈枝・肝静脈・下大静脈（実測）。どちらが何を所有するかは
`organs/portalVasculature.js` に記載し、**両方を同時に描かない**ことを
`tests/liver-anatomy.test.js` が固定しました。

解剖樹をモデル駆動にするのが本来の到達点ですが、**やっていません**。
それは `reviewed` 済みの 2 シーン（門脈圧亢進症・肝腎症候群）が描くものを
——フローストリームが辿るパスも含めて——置き換える変更で、リファクタリングの
範囲ではなく**臨床レビューを通し直す変更**です。判断を仰ぎます。

### 2. 葉・区域の体積比の出典

較正目標として使っている「右 35 / 12 / 53、左 50 / 50」と肝区域の比率は、
**出典を伴っていません**。葉と一緒に教えられる概数であって、ある研究の測定値を
引いたものではありません。この環境からは文献に到達できず（egress 制限）、
確認できていません。該当箇所すべてに「出典なし」と明記済みです。

候補として同定はしましたが**読めていない**もの:
*Reference formulas for chest CT-derived lobar volumes in the lung-healthy
general population*, European Radiology (2024), doi:10.1007/s00330-024-11123-6。
出典を当てる場合はここを起点にしてください。
