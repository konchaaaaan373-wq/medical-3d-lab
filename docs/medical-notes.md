# 循環、保たれてる？（最小循環モデル）

## このモデルが答える問い

**MAP が 70 mmHg なら、末梢への酸素供給も保たれていると言えるか。**

このプロトタイプは、心拍出量が 3.6 L/min と少ない一方、体血管抵抗が高いため
MAP が 70 mmHg に見える単一の概念症例です。画面に残す読み取りは CO・MAP・DO₂、
操作は輸液・DOB の2つだけです。Hb 10.5 g/dL、SaO₂ 97%、PaO₂ 85 mmHg は固定し、
酸素含量を動かす軸はこのプロトタイプでは扱いません。

使う定義は次の4つです。

```text
CO   = HR × SV / 1000
MAP  = CVP + CO × SVR / 80
CaO₂ = 1.34 × Hb × SaO₂ + 0.003 × PaO₂
DO₂  = CO × 10 × CaO₂
```

したがってこの固定条件では、DO₂ は CO とともに変化します。MAP は CO だけでなく
SVR にも依存するため、CO や DO₂ の変化を過小に見せることがあります。これは
「MAP を見なくてよい」という意味ではなく、**MAP だけで循環全体を証明できない**
という最小の理屈を見せるものです。

## 介入の境界

- 輸液は**輸液反応性あり**と仮定し、1回拍出量が増える向きだけを示します。
  実際の患者が反応するか、どれだけ投与すべきかは予測しません。
- DOB は収縮性と心拍数を上げ、この症例では SVR を下げる設定です。方向は臨床的な
  血行動態と整合させていますが、ボタンの「1段階」は用量ではありません。
- 両介入の効果は飽和関数で置いた例示値です。相互作用、有害事象、充満圧、うっ血、
  不整脈、心筋酸素需要、微小循環、酸素抽出、VO₂ は実装していません。
- 3D の粒子速度・血管リング・末梢組織の発光は、同じ state の CO・MAP・DO₂を
  読みやすく変換した演出値で、流体計算や組織酸素分圧ではありません。

数式と較正は `src/models/circulation.js`、画面文言は
`src/data/prototypes/circulation.js` にあります。

# アミロイドβの蓄積

## このモデルが表現していること

「**Aβ が増える → 集まる → 線維になる → プラークになる**」という
凝集カスケードの **概念** を、視覚的に理解しやすい形で示すことだけを目的にしています。

- Aβ は健常な脳でも産生・分解されており、正常状態でも少量が存在します
  （進行度 0% でも粒子がゼロにならないのはこのためです）。
- 産生と排出（クリアランス）のバランスが崩れると、可溶性 Aβ が蓄積すると考えられています。
- 可溶性オリゴマーは生物学的に重要な分子種と考えられ、シナプス機能障害との関連が
  報告されています（「神経毒性の主体である」と断定はしません）。
- 各凝集種（モノマー・オリゴマー・線維・プラーク）は **共存し、相互変換し得ます**。
  一方向の不可逆反応ではありません。本モデルでも最大凝集状態で
  モノマー 約18%・オリゴマー 約16%・線維 約20%・プラーク 約45% が共存します。
- 線維は β シート構造をとり、末端に Aβ が付加されることで伸長します。
- プラーク（老人斑）は **細胞外** の沈着物です。本モデルでも、
  すべての凝集体は細胞の外側にのみ配置しています。

## このモデルが表現していないこと

以下は意図的に省略・単純化しています。**実際とは異なります。**

- **スケール**：粒子・線維・プラーク・神経細胞の相対的な大きさは正確ではありません。
- **数**：粒子数は見やすさで決めた値で、実際の分子数とは無関係です。
- **時間**：スライダーの 0→100% は数十年単位の経過を数十秒に圧縮した概念的なものです。
  一定速度で進行することを意味しません。
- **分子構造**：Aβ40 / Aβ42 の違い、APP の切断過程、βセクレターゼ・γセクレターゼ、
  ApoE などの因子は登場しません。
- **タウ病理・神経炎症**：神経原線維変化、ミクログリア、アストロサイトの反応は
  含まれていません。アルツハイマー病の病理はアミロイドだけでは説明できません。
- **因果関係**：本モデルは「Aβ の蓄積が認知症を引き起こす」と主張するものではありません。
  アミロイドカスケード仮説をめぐる議論には立ち入っていません。
- **臨床病期ではありません**：スライダーは「凝集の状態」を動かすもので、
  臨床病期・重症度・症状の進行を表しません。
  **プラークの量は症状の重さと同一ではありません。**
- **中間種の簡略化**：protofibril などの中間種は独立したステージにしていません。
  オリゴマー → 線維 の連続的な変化の中に含めています。
- **Aβ40 / Aβ42 を区別していません**：一般的な Aβ の凝集として扱っています。

## 表現上のルール

- 神経細胞は凝集の進行に伴ってごくわずかに減光し、樹状突起スパインが少し小さくなります。
  これは「Aβ 病理とシナプスの変化に関連があると考えられている」ことの
  **模式的な示唆** であり、細胞死や用量反応関係を描いたものではありません。
  効果は途中で頭打ちになるよう設計し、スライダー末端まで悪化し続けないようにしています。
  「障害」「変性」などのラベルは付けていません。
- 解説文では「〜と考えられています」「〜のひとつです」といった表現を用い、
  不必要に断定的にならないようにしています。
- 画面上には常に「教育目的の簡易モデルです」という注記を表示しています。
  UI を非表示にしてキャプチャする場合は、投稿側で同等の注記を添えてください。

描画コードを触らずに編集できます。監修者のレビューを反映する場合はこのファイルを見てください。

# 心不全（HFrEF における左室リモデリングの一例）

## このシーンの位置づけ

**HFrEF（駆出率の低下した心不全）でみられる左室リモデリングと肺うっ血の一例を、
概念的に示した教育用模式図です。すべての心不全がこの経過をたどるわけではありません。**

求心性肥大から遠心性リモデリング・収縮機能低下へ進む経路は存在しますが、
心不全の普遍的な自然史ではありません。**HFpEF（駆出率が保たれた心不全）は
扱っていません。** ステージ名は経過の順序ではなく、形態と機能のパターンの名前です。

## 2 つの軸を分けています

```text
構造・機能の軸（ステージ）        血行動態のオーバーレイ
Normal                            肺うっ血
→ Concentric hypertrophy      ＋   （congestionLevel）
→ LV dilation
→ Systolic dysfunction (HFrEF)
```

**肺うっ血は左室リモデリングの「最終ステージ」ではありません。**
左心系充満圧の上昇に伴う血行動態の状態であり、構造的ステージとは別の軸です。
そのため本モデルでは、

- ステージ列（構造・機能の軸）は **Normal → 求心性肥大 → 左室拡大 → 収縮機能低下(HFrEF)**
  の 4 つだけとし、`Pulmonary congestion` を独立ステージにしていません。
- うっ血の強さは、循環モデルが解いた **平均肺静脈（肺毛細血管）圧 [mmHg]** から
  導かれます。ステージ表に書かれた値ではなく、左室の力学から出てくる圧です。
  スライダー後半で上昇しますが、ステージ名にはなりません。
- スライダー右端のラベルも「拡大・EF低下」という構造的な表現にしています。

> Pulmonary congestion is represented as a hemodynamic overlay rather than a
> structural remodeling stage.

**また、肺うっ血は HFrEF に特異的な所見ではありません。** HFpEF をはじめ、
左心系の充満圧が上昇する他の病態でも生じます。本モデルが HFrEF の文脈で
描いているのは、扱う対象を 1 つに絞っているためにすぎません。

## 求心性「肥大」と呼んでいる理由

標準的な心エコーの分類では、

- RWT 上昇 ＋ **LV mass 正常** = concentric remodeling（求心性リモデリング）
- RWT 上昇 ＋ **LV mass 増加** = concentric hypertrophy（求心性肥大）

です。本モデルはこのステージで **心筋容積を約 78% 増加**させ（内腔は約 5% 縮小、
RWT は 0.36 → 0.57）、明確に後者を表現しています。したがって
**「求心性リモデリング」という名称は不適切**であり、`Concentric hypertrophy /
求心性肥大` としています。

なお、この判断は**変化の向き**（心筋量が増える）に基づくものです。
本モデルの絶対的な mass 値は臨床的な計測値ではありません（後述）。

## このモデルが表現していること

- **求心性リモデリング**：壁が厚くなり内腔は拡大せず、相対的壁厚（RWT）が上昇します。
- **遠心性リモデリング / 左室拡大**：内腔が拡大して細長い形から丸みを帯びた形へ変わり、
  大きくなった心腔に対して壁は相対的に薄くなります（RWT 低下）。心筋量は増加したままです。
- **収縮機能の低下**：1回拍出量が徐々に低下し、EF が低下します。
- **心拍出量**：本モデルでは安静時の心拍出量が比較的長く保たれ（約 4.7 L/min）、
  その後ゆるやかに低下します（約 4.3 L/min）。これは狙って置いた値ではなく、
  収縮性が落ちる一方で循環血液量と体血管抵抗が上がる、という入力の組み合わせから
  **計算結果として出てくる**ものです。
  EF が低下していても安静時心拍出量が比較的保たれる患者がいる、という一例を
  示したものです。**すべての HFrEF がこの推移をたどるわけではありません。**
  1回拍出量や心拍出量が病態進行に伴って必ず単調に低下する、とも主張していません。
- **充満圧の上昇**：左室拡張末期圧（LVEDP）・平均左房圧・平均肺静脈圧が
  上昇します（正常 state では LVEDP 7.2 / 平均左房圧 7.5 / 平均肺静脈圧
  9.9 mmHg、スライダー右端で 32.3 / 29.0 / 31.2 mmHg）。これも与えた値ではなく、
  拡張末期圧-容積関係（EDPVR）と循環全体の釣り合いの結果です。
- **収縮期の壁の肥厚**：心筋を非圧縮と仮定した幾何から自動的に出てきます。
  不全心では肥厚の程度が小さくなることも同時に表現されます。
- **肺うっ血**：後述。

## 肺うっ血の表現（最重要）

**肺うっ血は、血液が左室から肺へ逆向きに流れて戻る現象ではありません。**

```text
LV 充満圧 ↑ → 左房圧 ↑ → 肺静脈圧 ↑ → 肺毛細血管静水圧 ↑ → 間質・肺胞への水分貯留
```

したがって本モデルでは、**血流** と **圧の上昇** を視覚的に完全に分離しています。

- **血液粒子** は生理的な方向にしか動きません。
  拡張期：左房 → 僧帽弁 → 左室、収縮期：左室 → 大動脈弁 → 大動脈。
  大動脈を逆行する粒子はありません（駆出された粒子は退出時に消え、
  充満期に左房側からフェードインします）。
- **うっ血** は圧のレイヤーとして描いています。充満圧の上昇に伴って、
  左房 → 肺静脈 → 肺血管床 の順に **圧のフロント（グロー）が外向きに広がります**。
  伝わるのは圧であって血液ではありません。
- **間質の水分** は、血管の**外側**に配置した淡い粒子として、圧が高くなってから
  出現します。血液とは色・大きさ・動きをすべて変えてあります。

**どこから描き始めるかは、モデルが解いた圧で決まります。** 以前は進行度に紐づいた
0〜1 の指数でしたが、現在は平均肺静脈（肺毛細血管）圧 [mmHg] を臨床的な目安に
当てています。

| 圧（平均肺毛細血管・肺静脈圧） | 画面 |
| --- | --- |
| 〜12 mmHg | 何も出ません |
| 12 → 30 mmHg | 圧のフロントが左房 → 肺静脈 → 肺血管床へ広がります（圧に比例） |
| 22 → 32 mmHg | 間質の水分が現れ始めます（閾値的な立ち上がり） |

肺水腫が起きる圧には個人差が大きく、慢性心不全では急性期より高い圧に耐えます。
この 4 つの数値は**描画のための対応表であり、臨床的な閾値ではありません。**
とくに、**間質の水分量を圧から臨床的に定量化しているわけではありません**
——実際にどれだけ水分が間質へ移動するかは、血管透過性・膠質浸透圧・
リンパ排出に依存し、本モデルはそのいずれも持っていません。
この対応表が担っているのは「オーバーレイが、誰かが手で置いた数値ではなく
**モデルが解いた圧とともに増減する**」という一点だけです。
なお、間質の水分は state が示す量を超えて発生させません。

肺胞・リンパ管・Starling 力・間質性浮腫と肺胞性浮腫の区別は描いていません。

## 比較モード（正常 vs リモデリング後）

`Compare` ボタン（キーボード `C`）で、**正常な左室を横に並べて表示**します。

これは監査で最後まで残った弱点への対処です。1 本のスライダーという UI は、
どれだけ注記を書いても「次にこうなる」という順序を示唆します。正常な心臓を
横に置くことで、**順番ではなく「別の状態」として比較**できるようにしています。

- 比較用の心臓は、**同じモデルを progress = 0 で評価**して描いています。
  別途チューニングした絵ではないので、モデルと食い違うことがありません。
- 両者は**心周期の位相を揃えて**います。壁厚と内腔の比較を優先したためです。
  心拍数の差（例：70 → 82 /min）は数値パネル側に出しています。
- 比較モードでは血管と肺うっ血のレイヤーを非表示にします。
  比較の対象は心腔の形と駆出であり、周囲の構造は画面を混雑させるだけだからです。
- 数値パネルは「正常値 → 現在値」の形式になります
  （例：EF `58 → 19 %`、LVEDP `7 → 32 mmHg`、平均肺静脈圧 `10 → 31 mmHg`）。
- 圧-容積ループも 2 本並びます。正常心の小さく背の高いループと、
  不全心の大きく背の低いループ、そして傾きの違う 2 本の ESPVR が同時に見えます。
- 圧波形も重ねて表示され、駆出の始まる時刻と左房圧の高さの違いが読み取れます。

## 「残存血液」について

**収縮末期の残存血液（ESV）は正常心にも存在します。病的な血流うっ滞ではありません。**

粒子は大動脈弁からの距離でランク付けされているため、流出路に近い血液から駆出され、
心尖部側の血液が残ります。これは **アニメーション上の演出** であり、
EF が下がるほど「入れ替わりにくい血液が増える（washout の低下）」という
概念を示すためのものです。

- 心尖部血栓の形成を再現していません。
- 実際の心内血流のうっ滞を再現していません。
- 粒子の動きは **流体シミュレーション（CFD）ではありません。**

## 数理モデルの作り

### 循環モデル（time-varying elastance）

心臓の動きと表示される数値は、**閉じた循環の常微分方程式を解いた結果**です。
EDV・ESV・壁厚のキーフレーム表はもうありません。スライダーが動かすのは
**力学的なパラメータだけ**で、EF も 1回拍出量も充満圧も、そこから出てきます。

```text
スライダーが動かすもの（力学）        モデルが解くもの（結果）
Ees（収縮末期エラスタンス）           EDV / ESV / SV / EF
V0（無負荷容積）                  →   LVEDP・左房圧・肺静脈圧・肺動脈圧
EDPVR の硬さ（β）                     大動脈圧（収縮期 / 拡張期 / 平均）
体血管抵抗・循環血液量・心拍数         駆出のタイミング（等容性収縮期の長さ）
```

- **心室・心房の圧**：Suga–Sagawa の time-varying elastance。
  `P(V, t) = e(t)·Ees·(V − V0) + (1 − e(t))·A·(exp(β·(V − V0)) − 1)`
  収縮末期は線形（ESPVR）、拡張末期は非線形（EDPVR）です。
  活性化関数 `e(t)` は double-Hill 型で、心房は心室より遅れて収縮します。
- **区画**：左室・大動脈系・体静脈系・右室・肺動脈系・肺静脈（＋毛細血管）系・左房 の 7 つ。
  各区画の容積を状態変数とし、`dV/dt = 流入 − 流出` を RK4 で積分します。
  **どの瞬間でも 7 区画の総和は循環血液量に等しくなります**（テストで担保）。
- **弁**：理想的な一方向抵抗。上流圧 > 下流圧 のときだけ流れ、逆流はゼロです。
  等容性収縮期・等容性弛緩期は、この条件から自然に出てきます。
- **定常解**：1 拍ごとに EDV / ESV が前拍と 0.02 mL 以内に収まるまで積分を繰り返します。
  スライダーを動かすたびに解き直しますが、直前の解をウォームスタートに使い、
  結果をキャッシュしているため、1 回あたり数ミリ秒です。

**右心系と肺循環は、描いていませんが計算はしています。** ループが閉じていなければ、
左室が弱ったときに血液が肺静脈側に貯まる、という肺うっ血の機序そのものが
成立しないためです。

### 前負荷・後負荷スライダー

`Loading conditions` の 2 本は、**モデルの出力を上書きするものではなく、
入力を変えるもの**です。前負荷は循環血液量に、後負荷は体血管抵抗に掛かり、
循環全体が解き直されます。

- 前負荷を上げると EDV が増え、1回拍出量が増えます（Frank–Starling 機構）。
  同時に充満圧も上がります。「増やせば良い」わけではないことが同時に見えます。
- 後負荷を上げると 1回拍出量は減り、動脈圧は上がります。
  **その減り方は Ees の低い（＝不全）心のほうが大きくなります。** これは
  エラスタンスモデルから自然に出てくる性質で、どこにも書き込んでいません。

### 圧-容積ループ

左側のパネルは、解かれた 1 拍をそのまま P–V 平面に描いたものです。
点線は ESPVR と EDPVR、すなわち**その拍を生んだ式そのもの**です。
ループの左上隅が ESPVR に、右下隅が EDPVR に接するのは、当てはめた結果ではなく、
同じ方程式を積分した結果です。比較モードでは正常心のループも並べて表示します。

### 圧波形

その下のパネルは、**同じ 1 拍を容積ではなく時間に対して**描いたものです。
ループが「心室が何をしたか」を示すのに対し、こちらは「なぜそうなったか」を示します。

- 左室圧が大動脈圧の線を上向きに横切ったところで大動脈弁が開き、下向きに
  横切ったところで閉じます。**等容性収縮期・等容性弛緩期は、その交点と
  容積が動き始める／止まる時刻とのすき間**として見えます。
  影を付けた帯は、解かれた流量から求めた「大動脈弁が開いている区間」です。
  線が交わって見える場所ではなく、実際に流れている区間を塗っています。
- 左房圧を同じ軸に載せているのは、充満圧の上昇こそが肺うっ血オーバーレイの
  主題だからです。ここではそれがグローではなく 1 本の線として読めます。
  拡張期に左房圧が左室圧を上回っていることが、僧帽弁が開いている理由です。
- 横軸は「1 拍」であり、固定の秒数ではありません。比較モードでは 2 つの心臓の
  心拍数が違う（例：70 と 88 /min）ため、右端に両方の 1 拍の長さを
  「正常 → 現在」の形式で出しています。

**このシミュレーション上の HFrEF state では**、正常 state と比べて
**大動脈弁の開放が遅く**（＝駆出の帯の左側のすき間が広い）、
**左房圧の線が高い位置にあります**。どちらも書き込んだ挙動ではなく、
エラスタンスモデルから出てくる帰結です。

ただしこれは **「HFrEF では等容性収縮期が延長する」という一般則ではありません。**
実際の等容性収縮時間は心拍数・前後負荷・伝導・収縮予備能などでも動き、
本モデルはそのうち一部しか変化させていません。ここで言えるのは
「この 2 つの simulated state を比べるとそうなる」ということだけです。

### 左房圧波形について

左房圧のトレースには **v 波（心室収縮期に、閉じた僧帽弁に対して肺静脈から
左房が充満する）** と **a 波（心房収縮）** が出ます。正常 state での値:

| | 圧 | 位相 |
| --- | --: | --- |
| v 波 | 12.1 mmHg | 0.50（駆出終了の直後） |
| a 波 | 8.0 mmHg | 0.89（拡張後期） |
| 谷 | 4.8 mmHg | 0.65 |
| 平均左房圧 | 7.5 mmHg | — |

**どちらの波が高いかは、モデルの要件にしていません。** 実際の左房では v 波の
ほうが高いことが多いのですが、その大小は心拍数・心房収縮性・負荷条件でも動き、
本モデルが保証できる性質ではないためです。テストで確認しているのは
「両方の波が実際の振れとして存在すること」「v 波が a 波より前に来ること」
「v 波が駆出中〜直後にピークを取ること（＝その機序どおりの位置にあること）」
の 3 点です。

これは監査で見つけた不具合の修正でもあります。以前の左房は EDPVR の係数
（`edpvrA` = 0.35）が小さく、左房が実際に動く容積範囲で **受動項が 1〜3 mmHg
しか出ていませんでした**。圧のほとんどが心房収縮の項からしか出ないため、
**v 波がほぼ立たず、a 波だけが目立ち、平均左房圧が左室拡張末期圧より
数 mmHg 低いまま**になり、肺循環側が左室から実質的に切り離されていました。
係数を 2.0 に上げ、同じ容積範囲で受動項が概ね 4〜12 mmHg 出るようにしています。

> **これらは本モデルの較正パラメータであり、計測値ではありません。**
> この関係式の局所的な傾き（mL/mmHg）を臨床的な左房コンプライアンスの計測値と
> 同一視しないでください。7 区画の集中定数ループのうち 1 区画が妥当な圧を出す
> ように当てはめた 1 本の指数関数にすぎず、心房壁の力学・粘弾性・
> reservoir / conduit / pump の分解などは背後にありません。

**再現していないもの:**

- **x 谷・y 谷の細部**：谷は 1 つの滑らかな下降として出るだけで、
  x 谷と y 谷を区別できる形にはなっていません。
- **c 波**：僧帽弁の膨隆に対応する成分は含みません。
- **dicrotic notch（重複切痕）**：集中定数モデルのため大動脈圧波形には出ません。
- **圧の絶対値の臨床的読み替え**：模式的な値であり、
  カテーテル計測値として読むものではありません。

### 心筋の非圧縮性（2 階層）

幾何のほうは引き続き **2 階層モデル** です。心筋を非圧縮として扱う仮定は
「1 心拍の中」でのみ有効で、病態ステージ間では心筋量そのものが変化してよいためです。

```text
病態ステージ
  → 拡張末期の内腔容積（循環モデルが解いた値） + 拡張末期の壁厚
  → そのステージの心筋容積            ← ステージ間では変化する
  → 1 心拍の間は一定                  ← 非圧縮の仮定はここだけ
  → 収縮期の壁肥厚が幾何から自然に出る
```

内腔は回転楕円体（長軸/短軸比 `longToShortAxisRatio`）として近似しています。
この比は臨床の sphericity index と同じ向きに動きますが、
**臨床計測値ではなく本モデルの形状パラメータ** です。

画面の形、圧-容積ループ、圧波形、そして右側の数値
（EF / EDV / ESV / SV / HR / CO / LVEDP / 肺静脈圧 / 動脈圧 / 壁厚）は、
**すべて同じ解から導かれています**。

## UI に出していない数値

- **左室心筋重量**：内部では計算していますが表示しません（心筋密度 1.05 g/mL を明示）。
  **この値は幾何学的な整合性のために内部で用いているだけで、臨床の心エコーによる
  LV mass 計測値ではありません。** 切断楕円体近似から得られる値であり、
  臨床的な正常範囲との比較にも使えません（LV mass の基準値自体、性別・体格・
  計測法・indexing に依存します）。本モデルで意味があるのは絶対値ではなく、
  **ステージ間で心筋量が増加するという向き** だけです。
圧については逆に、**mmHg の数値を出すようになりました。** 以前は「やや上昇 / 上昇」
といった定性表示にしていましたが、これは根拠のある圧を計算できなかったためです。
現在の圧は循環モデルが解いた値なので、単位付きで表示しています。ただし
**表示は 1 mmHg 刻み**で、それ以上の桁は出しません（集中定数モデルの精度を超えるため）。

## このモデルが表現していないこと

- **HFpEF（駆出率が保たれた心不全）**：扱っていません。
  なお肺うっ血は HFrEF に特異的ではなく、HFpEF でも生じます。
- **右心系・肺循環・体循環の「描画」**：計算はしていますが、画面に描いているのは
  左室・左房・大動脈起始部・肺静脈だけです。右室不全・肺高血圧そのものを
  主題にしたシーンではありません。
- **集中定数モデルであること**：区画は 1 つあたり 1 つの圧しか持たず、血管の慣性
  （inertance）・波動伝播・分布定数的な性質は含みません。したがって圧波形の細部
  （dicrotic notch など）は再現されません。肺静脈区画は毛細血管床を含めて 1 つに
  まとめてあり、その圧を間質への水分移動の駆動圧として扱っています。
  心房収縮期には肺静脈側へ血液がわずかに押し戻されます（実際にも肺静脈血流の
  心房逆行波として観察されます）が、集中定数近似のため実際よりやや大きめに出ます。
- **弁の動き**：弁は理想的な一方向抵抗として計算しており、弁輪はリング状の目印で
  開閉しません。逆流（僧帽弁閉鎖不全・大動脈弁閉鎖不全）や狭窄も含みません。
- **原因疾患**：虚血性・弁膜症性・高血圧性・心筋症などの違いは描いていません。
- **神経体液性因子**：RAA 系・交感神経系の活性化は描いていません。
  心拍数の上昇のみをキーフレーム値として与えています。
- **治療の影響**：薬物・デバイスによる逆リモデリングは含みません。
- **形態**：右室は外形のみの文脈的な膨らみで、右室腔・右室機能・
  心室間相互作用は含みません（後述）。乳頭筋・腱索・弁尖は**模式的に**
  描いています（後述）——弁の力学は計算していません。

## 3D 形状・質感の解剖学的シェーピングについて

チャンバーの 3D 形状は、循環モデルが解いた **内腔容積・心筋容積・長短軸比** を
唯一のスケールとして、その上に固定の「形の場」を重ねて描いています
（`geometry/ventricleGeometry.js`）。重要なのは、これらがすべて
**再配分であって増減ではない**ことです：

- **壁厚の場**（心尖部で薄く、中隔で厚い）は平均が約 1 になるよう設計し、
  解かれた心筋容積を保ったまま分布だけを変えます。描かれた壁厚が解かれた
  壁厚を数 % 以内で追随することはテストで担保しています
  （`tests/chamber-geometry.test.js`）。
- **中隔側の扁平化・心尖の側方偏位・表面の微小な凹凸**は視覚的な
  もっともらしさのための形状パラメータで、いかなる計測値でもありません。
- **右室の膨らみ**は文脈的な目印にすぎません。右室腔はなく、拍動も左室外形に
  従うだけです。右心系の力学は（計算はしていても）描画していません。
- **心尖固定と弁輪降下**：収縮は base→apex の向きで描き、心尖はほぼ固定、
  弁輪（僧帽弁・大動脈弁のリング）が心尖方向へ降下します。長軸短縮の量は
  解かれた容積変化から出ますが、**どこを固定点にするか**は表示上の選択です
  （`APEX_PINNING`）。
- **捻れ（torsion）**：心尖が基部に対して回旋する動きを、駆出の進行 ×
  EF に比例した **例示的な振幅** で加えています（`TORSION_ILLUSTRATIVE_MAX`）。
  実際の捻れは HFrEF で低下する、という**向き**だけを表現したもので、
  角度は計測値ではありません。本モデルは捻れを解いていません。
- **切断面の線維感・心外膜の冠動脈様のテクスチャ**は手続き的な質感であり、
  実際の線維走行・冠動脈解剖を表しません。
- **乳頭筋・腱索・僧帽弁尖・大動脈弁尖**は模式表現です。乳頭筋は前外側・
  後内側の 2 群のみで、腱索は代表的な数本、弁尖は前尖・後尖（僧帽弁）と
  3 尖（大動脈弁）の簡略膜です。**開閉のタイミングだけ**が本物です——
  循環モデルが解いた弁の開閉位相（駆出の開始・終了、充満）に従って
  動きます。弁の力学・逆流・狭窄・腱索張力はモデルにありません。
- **肉柱（trabeculae carneae）**は心尖部〜中位の内腔面の起伏として
  模式的に描き、流出路は滑らかにしています。実際の肉柱解剖の再現では
  ありません。
- **肺静脈は 4 本**（左右 2 本ずつ）を模式的に描き、その先の分枝は
  「肺血管側へ続く」ことを示す簡略表現です。
  うっ血時の静脈拡張（engorgement）・暗色化は圧上昇に伴う変化の模式表現で、
  拡張の量は計測値ではありません。暗色化の色は「うっ血した静脈組織の
  暗い赤紫」に向かわせています（青紫ではありません——うっ血した左房が
  安静時より*明るい*ラベンダーになっていたのを修正しました）。
- **左房**は分葉のある一つの腔として描いています。心耳・4 つの静脈開口部・
  僧帽弁へ向かう漏斗はいずれも形の目印であって、左房の実寸・容積・
  コンプライアンスを表すものではありません。うっ血時の左房拡張も同様に
  模式表現で、拡張率は計測値ではありません。
- **房室接合部（AV junction）の襟**は、僧帽弁輪から左房底へ連続していることを
  示すためだけの形状です。線維輪・房室中隔の解剖を表してはいません。
- **座標系**: `+x = 解剖学的左`・`+y = 上`・`+z = 前` の右手系で、既定カメラは
  前方から見ます。したがって**解剖学的左は画面の右**に見えます——患者に正対したとき、
  あるいは胸部 X 線を読むときと同じ向きです。
  かつて心室と血管系がこの規約について食い違っており（心室は正しく、血管・弁・左房が
  鏡像でした）、各構造は隣接構造との関係だけは正しいまま全体が反転していました。
  現在は血管側を心室の座標系へ揃えてあります（`ANATOMICAL_AXES`,
  `tests/semantic-anatomy.test.js`）。
- **肺静脈 4 本の開口位置**は左房の後壁上に模式的に配置しています。実際には右肺静脈は
  左房の右縁（ほぼ正中）に入りますが、本モデルでは左房本体との位置関係を保つことを
  優先し、4 本とも正中よりやや左側から入る形にしています。
- **左右の肺**は輪郭のごく淡いコンテキストとしてのみ描いています。肺血管床が
  暗闇に浮かないようにするための背景であって、肺葉・葉間裂・気管支・
  肺実質のいずれも表現していません。左右の大きさの差と心切痕は「左右対称の
  図形に見えないようにする」ための最小限の形状差で、解剖学的な計測ではありません。
- **大動脈**は基部（Valsalva 洞）から弓部・下行大動脈までを一本の管として
  描き、遠位側はフレーム外へ向けて徐々に透明にしています。切断端を見せない
  ための表示上の処理で、大動脈がそこで終わることを意味しません。弓部から
  分岐する腕頭動脈・左総頸動脈・左鎖骨下動脈は描いていません。
  管の始点は大動脈弁の高さに置いています——それより下の左室流出路は心室であり、
  心室が描く領域だからです。

## 数値について

表示される EF・EDV・ESV・SV・CO・LVEDP・肺静脈圧・動脈圧は、
**循環モデルを解いた結果**であり、表に書かれた値ではありません。
一方、その入力となる力学パラメータ（Ees・V0・EDPVR の硬さ・体血管抵抗・
循環血液量・心拍数・壁厚）は、各パターンの教科書的な代表例を意識して選んだ
**一例**です。実際の症例では大きくばらつきます。

計算結果がモデルとして一貫していることと、臨床的に代表的であることは別の話です。
既知のずれとして、本モデルの平均動脈圧はスライダー全域で概ね 95〜110 mmHg に
とどまります（心拍出量の低下が緩やかな一方で体血管抵抗が上がるため、モデル内部
では整合しています）。実際の HFrEF の経過では、これより血圧が下がる例が
少なくありません。

**EF の値だけで心不全の重症度は判断できません。**

## The end-diastolic outline

In the comparison, and during the two beat steps of the guided sequence, a thin
cage marks where the endocardial surface sat at end-diastole. It is drawn from
`ventricleShape()` evaluated at the state's own `edvMl` — the same function that
draws the beating chamber, at a different volume. Nothing about it is hand-drawn,
and it carries no value the model does not already produce.

It is drawn as lines rather than as a surface so that it cannot be read as
tissue: it is a measurement mark, and the gap between it and the moving lining is
the stroke. Its opacity follows how far through the stroke the cavity currently
is, so at end-diastole (where it lies exactly on the lining) it is not drawn at
all.

What it is **not**: it is not an imaging measurement, not a wall-motion score,
and the gap is not a quantified stroke volume. It is there so that "this
ventricle empties less" is something the viewer sees rather than reads.

- **数値を一切出していません。** 進行度スライダーは「呼吸の深さ」「運動パターン」

- **動きの速さは説明のための値です。** 呼吸数・蠕動の周期・粒子の速度は
  見て分かることを優先した presentation 値で、生理学的な計測値ではありません
  （コード上も `speed` / `rate` / `phase` など演出値と分かる名前にしてあります）。
- **粒子は「向きと勢い」の表現であって流量ではありません。** 圧から速度を
  解いてはいません。粒子の数・密度は、細胞数・分子数・血球数のいずれでもありません。
- **半透明表示は演出です。** 肝臓・膵臓・甲状腺・脾臓・腎臓・膀胱を透かして
  いるのは内部の流れや構造を見せるためで、組織の性質ではありません。
- **顕微構造を描いていません。** 肺胞・ネフロン・肝小葉・膵腺房・濾胞上皮・
  骨梁・筋節はいずれも構造として描いていません。膵島・甲状腺濾胞は
  「そこに何かがある」ことを示す模式的な球です。
- **神経支配・ホルモン制御・自律神経の調節を描いていません。**

## この段階で意図的にやっていないこと

prototype の目的は「全身に広げても破綻しない構造」を確認することであり、
各臓器を完成させることではありません。したがって現時点では、

- 医学的レビューを受けていません（`reviewed` 以上の条件です）
- 医学モデル（式）が形と数値を駆動していません（`alpha` の条件です）
- 数値パネル・グラフ・Learn 教材を持ちません

いずれかを実装するときは、[`adding-a-scene.md`](adding-a-scene.md) の
**status を上げる条件**に従って、同時に status を上げてください。
**status を上げずに数値を出さないでください。** バッジが消えるということは
「この画面の数字は信じてよい」と言うことです。

## 2026-08 の実描画監査で直したこと

プロトタイプ 14 シーンをブラウザで確認し、**医学的に誤解を生む描画**を修正しました。
形状の作り込みではなく、誤りの除去です。

- **気管支が肺に届いていなかった**（肺が低く・離れすぎていた）。肺尖が気管分岐部より
  上に来る位置に修正
- **食道が胃の手前で終わって見えていた**。食道が胃底の後方から入るように変更
- **幽門から内容物が空中へ流出していた**。十二指腸球部を追加し、内容物が消化管内に
  留まるように変更
- **膀胱のラベルが臓器から大きく離れていた**（臓器ビルダー座標系のアンカーを
  world 座標として使っていた）。腸管・副腎でも同種のずれを修正
- **全身像で心臓が肺より大きく見えていた**。胸腔は肺が占め、心臓はその間に収まる
  比率に修正。腎臓は腸管に完全に隠れていたため、後方に置いたまま外側へ寄せて
  可視化
- **副腎シーンで、主題である副腎が隅に小さく写っていた**。副腎を基準にフレーミング

**2 巡目で追加した修正:**

- **子宮内膜が子宮のほぼ全体を占めて見えていた**（最も厚い時期に内膜が筋層の
  内縁まで達していた）。「子宮の大部分は内膜」という誤解を生むため、内膜は
  常に筋層の内側に収まる比率に変更
- **小腸が「積み重なった帯」に見えていた**。腹腔中央から放射状に重なるループに
  作り直し、腸管が「長い管を狭い空間に折り畳んだもの」だと読めるように変更
- **脾臓が特徴のない卵形だった**。上縁の切痕を正面から見て分かる深さにし、
  形状をより細長く変更

いずれも「精度を上げた」のではなく、**明らかな誤りと、臓器と認識できない形状を
取り除いた**修正です。形状・寸法・速度がプロトタイプ相当であることは変わりません。

## 2026-08 の概念監査で直したこと

実描画監査が「臓器として読めない形」を直したのに対して、こちらは
**動きが述べている因果そのものが間違っていた**箇所を直しました。形は
prototype のままです。直したのは、**動きが主張している内容**です。

- **前立腺：流量に 4 乗則を当てていた。** `flow = calibre⁴` は Poiseuille の
  定常層流の関係で、排尿にも、ポンプも compliance も圧もないこのシーンにも
  当てはまりません。流量法則そのものを取り除き、画面に出すのは**内径**だと
  言い切りました
- **腎臓：皮質から腎盂への粒子経路が「尿ができる過程」に見えていた。**
  尿細管での再吸収・分泌・濃縮を丸ごと飛ばしていることを、ラベルと注記の
  両方で明示しました（`皮質（濾過）` → `集合系（腎盂）`）
- **骨：吸収と形成がカップリングしていなかった。** 2 つが独立に光っていたため、
  「リモデリングとは吸収の *あとに* 形成が来る一続きの過程である」という
  中心的な事実が抜けていました。吸収が先行し形成が後続する時間窓を導入し、
  スライダーが**累積結果**であること（画面上のサイクルが骨を削るのではない
  こと）を注記しました
- **骨格筋：加重・強縮が「書き分けられて」いた。** 段階ごとに振幅を変えて
  いたため、なぜ融合するのかが表現されていませんでした。軸を**刺激頻度**に
  変え、単収縮を臨界減衰 2 次系の応答として重ね合わせることで、加重も強縮も
  **創発**するようにしました。刺激そのものを運動点のフラッシュとして描き、
  **入力は融合しないが応答は融合する**という対比を見えるようにしました
- **副腎：「ストレス反応強度」という軸そのものが誤りだった。** このシーンの
  主題は時間差なので、強度軸ではそれを表現できません。軸を
  **ストレッサー開始後時間（0〜90 分）**に変え、SAM と HPA を
  *別の経路として* 描き分けました（髄質へ直接届く**神経**と、下垂体から
  血流で運ばれて皮質に届く **ACTH**）。曲線は
  [`response.js`](../src/scenes/endocrine/scenes/adrenalResponse/response.js)
  の一次コンパートメント連鎖から出しており、コルチゾールの遅れは
  書き込まれた値ではなく **3 段カスケードの帰結**です。
  あわせて「持続刺激で皮質が肥大する」描写を削除しました — 90 分の軸で
  腺は肥大しません

# モデル層を持つ 3 シーン（COPD / 喘息 / 肝硬変）

この 3 つは prototype ではありません。**画面上のすべての数値が 1 つの医学
モデルから出ています**（`src/models/`）。したがって「何を簡略化したか」を
書く責任も重くなります。各シーンの完全な境界は
[`docs/model-cards/`](model-cards/) に、主張の出どころは
[`docs/model-evidence/`](model-evidence/) にあります。ここに書くのは、
**この 3 つに共通する制約**と、**特に誤解されやすい点**だけです。

## 3 つに共通すること

- **外部の臨床レビューによる指摘を反映済みですが、修正後の再レビューは
  受けていません。** いずれも status は `alpha` のままです。レビューは 3 シーン
  すべてで実際の誤りを見つけました（COPD：気道狭窄だけではエアトラッピングが
  起きないという誤った一般命題。喘息：喘息を末梢気道疾患と読ませる気道解剖と、
  深吸気の気管支拡張反応に定量的な大きさを付けた教材。肝硬変：因果の順序の反転、
  側副血行路の説明の単純化しすぎ、瞬時開通と読める記述、HVPG の過剰主張、
  門脈血栓症を前類洞性の原因として列挙）。詳細は各 dossier 冒頭の
  「What the review corrected」にあります
- **構築環境からは、いまも出典の本文に到達できません。** 医学系出版社
  （PubMed / PMC / Nature / ERS / ATS / Wiley / BMJ など）はこのネットワークから
  到達できないままです。したがって、図表や methods から数値を取り出したものは
  1 つもありません。上記のレビューが解決したのは因果関係と解釈に関する主張で
  あって、**較正値が実測値へ昇格したものは 1 つもありません**
- **主張ごとの確信度を機械可読にしました。**
  [`src/models/evidence.js`](../src/models/evidence.js) に、各主張が
  `established` / `supported` / `calibration` / `illustrative` / `uncertain`
  のどれであるかを書いてあります。`tests/evidence.test.js` が、断定している
  主張には必ず実在するテスト名が付いていること、較正値・説明用の値には
  「それが何ではないか」が書かれていることを検査します
- **テストを 3 層に分け、「事実」と「モデルの都合」を分離しました。**
  詳細は [`tests/README.md`](../tests/README.md) にあります。
  1. **External physiology**（`tests/respiratory-physiology.test.js`,
     `tests/portal-haemodynamics.test.js`,
     `tests/hepatorenal-physiology.test.js`）— このリポジトリが存在しなくても
     成り立つ命題。**このリポジトリが選んだ定数に依存する主張を 1 つも
     含みません。** 方向・順序関係・独立性のみで、大きさや比率は書きません。
     **ここが落ちたときにだけ**「モデルが生理学的制約を破った」と言えます。
  2. **Model integrity**（各 model / scene テスト）— 保存則・有限性・決定性・
     solver の収束、および「グラフ＝数値＝3D＝教材がすべて同じモデルを
     読んでいること」。落ちても医学の話ではありません。
  3. **Calibration behaviour**（`tests/calibration.test.js`）— このリポジトリが
     意図的に選んだ parameterization が設計どおり働くこと。基準肺の時定数、
     気管支拡張薬の 28% 対 10%、末梢/中枢の constrictibility 比、
     dynamic component の 30%、健常肝の圧較差と血流、TIPS 全開で 12 mmHg を
     下回るかどうか。**ここが落ちても「医学が間違った」とは言いません。**
     このリポジトリの選択が変わった、という意味です。
  この分離は `src/models/evidence.js` の `LAYER` と `defineEvidence`、および
  `tests/evidence.test.js` が機械的に強制しています（主張の種類と、それを
  守っているテストが実在するファイルの層とを突き合わせます）
- **定数の多くは較正値です。** 実測へのフィッティングは 1 つも行っていません。
  「健常肺の時定数を 0.55 秒にする」「健常肝の圧較差を 3 mmHg にする」
  といった教科書的な代表値に合わせるための数値であり、コード上で
  calibration と明記してあります
- **時間の扱いが違います。** COPD は呼吸ごとに積分する動的モデル、
  喘息と肝硬変は平衡状態を解くモデルです。後者に「進行に何年かかるか」
  は入っていません

## COPD：呼気流量制限と動的過膨張

| | |
| --- | --- |
| 表現していること | τ = R·C による肺の排出、呼気時間が足りないときの呼気終末肺気量の落ち着き先、**呼吸パターンと呼気努力を固定すれば気道抵抗の上昇だけで過膨張が起きること**、呼気努力が効く範囲と流量上限に達して効かなくなる境目、気管支拡張薬が過膨張に効く理由 |
| 特に注意 | **気道抵抗・弾性収縮力・呼気時間・呼気筋圧の 4 つを互いに独立に保っています。** 以前は呼気筋圧を吸気ドライブから導出していたため、気道抵抗を上げると呼気努力まで一緒に上がり、時定数の延長が生むはずのエアトラッピングを打ち消していました。その結果シーンは「狭い気道だけでは空気は閉じ込められない」という誤った一般命題を教えていました。喘息の誘発気管支収縮が示すとおり、これは誤りです。**ガス交換をまったく扱っていません**（SpO₂・PaO₂・PaCO₂ を出しません）。肺気量からは導けないためで、モデルがそのキーを持たないことをテストで固定しています。**流量上限は全肺気量付近で過小評価します**（実際の最大流量は wave-speed 律速で、このモデルは equal pressure point の粘性律速のみ）。ピークフローとして読めません。**このモデルでは努力がエアトラッピングを悪化させません**。実際の流量制限肺では努力呼気が悪化させ得ます。呼吸パターン（回数・duty cycle）は負荷から与えており、モデルが選んでいません |

## 喘息：不均一な気管支収縮

| | |
| --- | --- |
| 表現していること | 分岐気道をネットワークとして解いた流れの分配、実質の牽引を介した気道狭窄の自己増幅、それによる換気の不均一化とクラスター状の換気欠損、刺激量-反応曲線の変曲点、**肺気量が増えると実質の牽引力が増して気道狭窄に抗するという力学的関係** |
| 特に注意 | **喘息は気道樹全体の疾患であり、末梢気道だけの疾患ではありません。** 気道平滑筋は気管（後壁膜様部の trachealis）から終末細気管支まで存在します。末梢に向かって失われるのは、それに抗する軟骨のほうです。モデルはこの 2 つを `smoothMuscleFraction` と `cartilageSupport` として分けて持ち、その積 `constrictibilityWeight` を解に使います。**肺伸展の操作項は「深呼吸」ではありません。** 力学的な牽引効果だけを取り出したもので、喘息患者が実際に深吸気をしたときの気管支拡張反応を予測しません。その反応は喘息では減弱ないし消失しており、それを説明する平滑筋の動的性質（伸展速度・クロスブリッジの回転・収縮装置の可塑性）はモデルにありません。**Venegas らのモデルを再現したものではありません。** 発表された機序に着想を得た簡略化された概念実装です。**すべて相対値です。** Poiseuille 則は「4 乗に効く」という相対的主張として使っており、実際の気道抵抗の値ではありません（太い気道の流れは層流ではない）。8 世代・対称分岐で、実際の肺は 23 世代・非対称です。**「隣接」は樹構造上の定義**であり、空間的な隣接ではありません。**最大刺激では「欠損領域の割合」が下がります** — 均一に閉じた肺には相対的な欠損が存在しないためで、そこでは肺全体に届く空気の量を読む必要があります。ガス交換・血流・灌流はありません。フィードバックの結合指数（`TETHERING_COUPLING`）はこのモデルの挙動が最も敏感に依存するパラメータで、導出されたものではありません |

## 肝硬変：門脈圧と血液の行き先

| | |
| --- | --- |
| 表現していること | ΔP = Q·R を流量保存が成り立つネットワークに適用したときの門脈圧、**肝内抵抗の上昇という起点となる機序と、内臓循環からの流入増加という維持・増悪の機序**、側副血行路が門脈血を再分配しても圧が下がりきらない理由、HVPG が門脈圧較差ではない理由、短絡路が下げる圧と失う灌流 |
| 特に注意 | **因果の順序が重要です。** 肝内血管抵抗の上昇が起点であり、慢性の門脈圧亢進が内臓血管拡張と hyperdynamic circulation を誘導し、その結果の流入増加が圧を維持・増悪させます。並列した 2 つの原因ではありません。モデルは平衡モデルで時間を持たないため、この順序は walk-through が与えており、そのことも明記しています。**計算しているのは門脈圧較差であり、HVPG ではありません。**両方を常時表示しています。HVPG = WHVP − FHVP であり、類洞性門脈圧亢進では WHVP が類洞圧を「近似」します（直接測定ではありません）。閾値は Baveno VII に従い、5 mmHg 超で門脈圧亢進、10 mmHg 以上で CSPH です。**12 mmHg を一般的な非代償化の閾値としては使っていません** — 静脈瘤出血との古典的関連と TIPS 術後の目標圧較差という文脈に限定しており、HVPG の区分に 12 mmHg の境界はありません。閾値の適用可否は、連続値の比較ではなく**明示された血行動態パターン**（類洞性 / 混合性 / 前類洞性）が決めます。**前類洞性（肝内）と肝前性は別物です** — モデル化しているのは前類洞性（住血吸虫症・PSVD・一部の胆汁うっ滞性疾患）であり、門脈血栓症は肝前性でモデル化していません。**側副血行路の抵抗値は較正定数です** — 「側副血行路は常に高抵抗」という一般則ではありません。太く大量の血流を運ぶ自然短絡もあり、それでも門脈圧亢進は続きます。側副血行路のシグモイドは**平衡マッピングであって瞬時開通ではありません**（実際は数か月〜数年の拡張・リモデリング・血管新生）。**腹水は扱いません** — 門脈圧だけからは導けず、モデルがそのキーを持たないことをテストで固定しています。静脈瘤・出血リスク・肝性脳症・肝機能（Child-Pugh / MELD）もありません。**シーンの主軸（肝内線維化の進行）では肝門脈血流は低下します**（テストで各段階を固定）。肝内抵抗を固定したまま内臓血管拡張だけを上げると増加しますが、これは ΔP = Q·R の算術であってバグではありません。実際の肝硬変肝で hyperdynamic circulation があっても灌流が低下する要因（肝内血管床の進行性閉塞、流入を上回る側副血行路の発達）はモデルにありません。平均動脈圧と肝静脈圧は固定で、非代償期の実際とは異なります |

## この 3 つで意図的にやっていないこと

- **臨床判断につながる出力**。診断・重症度判定・治療選択・予後のいずれも出しません
- **患者個別の予測**。どのシーンの肺・肝臓も「1 例」であって代表例ではありません
- **ガイドラインの図表の複製**。使ったのは、多くの文献で文章として述べられている
  数値の閾値のみです

# 肝腎症候群 HRS-AKI（`hepatorenal-syndrome`）

臓器横断シーンです。肝臓のモデル
（[`src/models/portalHypertension.js`](../src/models/portalHypertension.js)）を
再実装せずに import し、体循環と腎臓を足して、**平均動脈圧という 1 つの未知数**
について同時に解いています。

詳細は
[`docs/model-evidence/hepatorenal-syndrome.md`](model-evidence/hepatorenal-syndrome.md)
と [`docs/model-cards/hepatorenal-syndrome.md`](model-cards/hepatorenal-syndrome.md)
にあります。ここには単純化した点だけを書きます。

## 最初に読むこと

**このシーンは、HRS-AKI のうち循環・神経体液性の機序を意図的に分離して示します。
このモデルには構造的腎障害を実装していませんが、実際の HRS-AKI で腎障害が存在
しないという意味ではありません。**

2024 年の ADQI–ICA 合同コンセンサス（Nadim MK ほか、J Hepatol 2024;81:163–183、
PMID 38527522）では、HRS-AKI は腹水を伴う進行肝硬変に特異的な AKI phenotype で
あり、**尿細管障害・蛋白尿・既存の CKD を伴っていても、また他機序の AKI と併存
していても成立し得ます**。

診断基準（2024）は次のとおりです。

- 腹水を伴う肝硬変
- AKI 基準の充足
- **臨床的に適応がある場合の**適切な輸液蘇生後 24 時間以内に改善しないこと
- 主因となる有力な代替説明がないこと

**48 時間の系統的アルブミン投与は診断の必須段階ではありません。**
**構造的腎疾患の非存在も絶対条件ではありません。** 本シーンの初版はこの 2 つを
旧来の絶対条件として書いていましたが、いずれも削除しました。

## このシーンが答える問い

**腎臓に一切の障害を与えていないモデルで、循環と神経体液性の変化だけで、
糸球体濾過量はどこまで低下し得るのか。**

「正常な腎臓がなぜ濾過をやめるのか」という初版の問いは一般化が強すぎました。

## 意図的に単純化したこと

- **腹水がありません。** HRS-AKI は**腹水を伴う**肝硬変で定義されるため、この
  phenotype を定義する臨床的文脈そのものが欠けています
- **構造的腎障害がありません。** 尿細管障害も、蛋白尿も、既存の CKD もありません。
  2024 コンセンサスがこれらの併存を許容している以上、**その不在はモデルの境界で
  あって症候群の特徴ではありません**
- **尿細管がありません。** ナトリウム処理も、尿量も、希釈性低ナトリウム血症も、
  機序としての尿細管糸球体フィードバックもありません。したがって
  **HRS-AKI を腎前性高窒素血症や急性尿細管壊死と区別できません**
- **心臓がありません。** 1 つの指数（`CARDIAC_COMPENSATION_EXPONENT`）が、
  収縮能・拡張能・心拍数・収縮性のすべてを代表しています。肝硬変性心筋症は
  その指数を下げる 1 つのスライダーです
- **時間がありません。** 平衡モデルです。**進行スライダーはパラメータ空間の中で
  選んだ 1 本の経路であって、時間経過でも自然史でもありません。** 肝内血管抵抗と
  動脈拡張を同時に動かしているのはシーンの筋書きのためです
- **血管収縮系の活性化は 0〜1 の指標です。** レニン・アンジオテンシン・
  アルドステロン・ノルアドレナリン・バゾプレシンをまとめて 1 つの無次元量で
  代表しています。単位はなく、**濃度として表示してはいけません**。
  有効循環血液量は単一の測定量ではないため、**それを駆動する観測可能な代理として
  動脈圧の低下量**を用い、全身の血管拡張はその上流の原因として別に表示します
- **内臓循環に内因性の活性化をフィードバックしていません。** 「内因性の血管収縮
  シグナルのもとでも内臓循環は相対的に拡張したままである」という不均衡は、
  創発ではなく作り込みです。「内臓血管床は反応しない」とは言えません
  （治療アームは実際に内臓血管を収縮させています）
- **膠質浸透圧は平均値 1 つです。** filtration pressure equilibrium は起こり得ません
- **輸出細動脈は傍尿細管毛細血管まで含めた 1 つの抵抗です**
- **自己調節は「機序」ではなく「幅」です。** 筋原性反応も尿細管糸球体
  フィードバックもありません
- **輸液に上限がありません。** アルブミンを十分に投与すれば血圧は正常を超えます。
  実際の患者では肺水腫になります
- **NSAIDs の作用を腎プロスタグランジン抑制だけに限定しています。** 腎臓の局所
  防御機構を単独で見るためのモデル上の分離であり、**実際の NSAIDs に全身作用が
  ないという意味ではありません**。ナトリウム・水の貯留、血圧への影響、血行動態性
  の急性腎障害、急性間質性腎炎などを起こし得ます。AKI のリスクは肝硬変だけでなく、
  脱水・慢性腎臓病・心不全・腎灌流低下でも上昇します
- **治療に不応例も有害事象もありません。** 血管収縮薬＋アルブミンによる改善は
  概ね 40〜50% 程度と報告されていますが、ここでは投与すれば必ず奏功します。
  **治療アームが示すのはモデルが予測する変化の向きであって、確実な臨床反応では
  ありません。** テルリプレシンの虚血性合併症は一切表現されていません

## 既知の「向きが怪しい」ところ

- **経過の初期に濾過量が正常をわずかに上回ります。** 輸入細動脈がまだ
  プロスタグランジンに保護されている間に輸出細動脈の収縮が働くためです。
  代償期肝硬変での過剰濾過は報告されていますが、このモデルはそれに合わせて
  較正されておらず、その大きさは主張ではありません。あえて調整で消して
  いないのは、消そうとすると後半の軌跡を正しくしている 2 つの機序のどちらかを
  弱めることになるからです
- **シグナルを除いた反実仮想が回復させるのは、どの重症度でも「灌流」です。**
  濾過が回復するのは**自己調節の破綻よりさらに後ろにある交差点以降**であり、
  それ以前はむしろ低下します（輸出細動脈の収縮が濾過を支えているため）。
  初版は「どの重症度でも濾過が戻る」と書いてテストに否定され、次の版は
  「自己調節破綻以降」と書きましたが、これも誤りでした。膝と交差点は軸上の
  別の位置です
- **心拍出量が上がり続けるわけではありません。** 心予備能が保たれた既定経路では
  各段階で上昇しますが、これはパラメータ設定です。肝腎症候群の発症時には
  心拍出量の低下が観察されており（Ruiz-del-Arbol、Hepatology 2005、PMID 15977202）、
  心予備能を下げれば同じ腎機能低下に別経路で到達します

## 「腎障害がない」ことはモデルの境界であって発見ではありません

このモデルには構造的な腎障害を表現する手段がありません。したがって
「シグナルを取り除けば循環由来の分は戻る」は、モデルが見つけたことではなく、
そう作ったことです。タイトル・サブタイトル・disclaimer・scope panel・reel note の
すべてが日英でそう述べており、テストがそれを検査しています。
