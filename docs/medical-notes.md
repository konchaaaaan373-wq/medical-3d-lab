# アミロイドβの蓄積

## このモデルが表現していること

「**Aβ が増える → 集まる → 線維になる → プラークになる**」という
凝集カスケードの **概念** を、視覚的に理解しやすい形で示すことだけを目的にしています。

- Aβ は健常な脳でも産生・分解されており、正常状態でも少量が存在します
  （進行度 0% でも粒子がゼロにならないのはこのためです）。
- 産生と排出（クリアランス）のバランスが崩れると、可溶性 Aβ が蓄積すると考えられています。
- 可溶性オリゴマーは生物学的に重要な分子種と考えられ、シナプス機能障害との関連が
  報告されています（「神経毒性の主体である」と断定はしません）。
- 各凝集種（モノマー・オリゴマー・線維・プラーク）は **共存し、相互変換し得ます**。
  一方向の不可逆反応ではありません。本モデルでも最大凝集状態で
  モノマー 約18%・オリゴマー 約16%・線維 約20%・プラーク 約45% が共存します。
- 線維は β シート構造をとり、末端に Aβ が付加されることで伸長します。
- プラーク（老人斑）は **細胞外** の沈着物です。本モデルでも、
  すべての凝集体は細胞の外側にのみ配置しています。

## このモデルが表現していないこと

以下は意図的に省略・単純化しています。**実際とは異なります。**

- **スケール**：粒子・線維・プラーク・神経細胞の相対的な大きさは正確ではありません。
- **数**：粒子数は見やすさで決めた値で、実際の分子数とは無関係です。
- **時間**：スライダーの 0→100% は数十年単位の経過を数十秒に圧縮した概念的なものです。
  一定速度で進行することを意味しません。
- **分子構造**：Aβ40 / Aβ42 の違い、APP の切断過程、βセクレターゼ・γセクレターゼ、
  ApoE などの因子は登場しません。
- **タウ病理・神経炎症**：神経原線維変化、ミクログリア、アストロサイトの反応は
  含まれていません。アルツハイマー病の病理はアミロイドだけでは説明できません。
- **因果関係**：本モデルは「Aβ の蓄積が認知症を引き起こす」と主張するものではありません。
  アミロイドカスケード仮説をめぐる議論には立ち入っていません。
- **臨床病期ではありません**：スライダーは「凝集の状態」を動かすもので、
  臨床病期・重症度・症状の進行を表しません。
  **プラークの量は症状の重さと同一ではありません。**
- **中間種の簡略化**：protofibril などの中間種は独立したステージにしていません。
  オリゴマー → 線維 の連続的な変化の中に含めています。
- **Aβ40 / Aβ42 を区別していません**：一般的な Aβ の凝集として扱っています。

## 表現上のルール

- 神経細胞は凝集の進行に伴ってごくわずかに減光し、樹状突起スパインが少し小さくなります。
  これは「Aβ 病理とシナプスの変化に関連があると考えられている」ことの
  **模式的な示唆** であり、細胞死や用量反応関係を描いたものではありません。
  効果は途中で頭打ちになるよう設計し、スライダー末端まで悪化し続けないようにしています。
  「障害」「変性」などのラベルは付けていません。
- 解説文では「〜と考えられています」「〜のひとつです」といった表現を用い、
  不必要に断定的にならないようにしています。
- 画面上には常に「教育目的の簡易モデルです」という注記を表示しています。
  UI を非表示にしてキャプチャする場合は、投稿側で同等の注記を添えてください。

描画コードを触らずに編集できます。監修者のレビューを反映する場合はこのファイルを見てください。

# 心不全（HFrEF における左室リモデリングの一例）

## このシーンの位置づけ

**HFrEF（駆出率の低下した心不全）でみられる左室リモデリングと肺うっ血の一例を、
概念的に示した教育用模式図です。すべての心不全がこの経過をたどるわけではありません。**

求心性肥大から遠心性リモデリング・収縮機能低下へ進む経路は存在しますが、
心不全の普遍的な自然史ではありません。**HFpEF（駆出率が保たれた心不全）は
扱っていません。** ステージ名は経過の順序ではなく、形態と機能のパターンの名前です。

## 2 つの軸を分けています

```text
構造・機能の軸（ステージ）        血行動態のオーバーレイ
Normal                            肺うっ血
→ Concentric hypertrophy      ＋   （congestionLevel）
→ LV dilation
→ Systolic dysfunction (HFrEF)
```

**肺うっ血は左室リモデリングの「最終ステージ」ではありません。**
左心系充満圧の上昇に伴う血行動態の状態であり、構造的ステージとは別の軸です。
そのため本モデルでは、

- ステージ列（構造・機能の軸）は **Normal → 求心性肥大 → 左室拡大 → 収縮機能低下(HFrEF)**
  の 4 つだけとし、`Pulmonary congestion` を独立ステージにしていません。
- うっ血の強さは、循環モデルが解いた **平均肺静脈（肺毛細血管）圧 [mmHg]** から
  導かれます。ステージ表に書かれた値ではなく、左室の力学から出てくる圧です。
  スライダー後半で上昇しますが、ステージ名にはなりません。
- スライダー右端のラベルも「拡大・EF低下」という構造的な表現にしています。

> Pulmonary congestion is represented as a hemodynamic overlay rather than a
> structural remodeling stage.

**また、肺うっ血は HFrEF に特異的な所見ではありません。** HFpEF をはじめ、
左心系の充満圧が上昇する他の病態でも生じます。本モデルが HFrEF の文脈で
描いているのは、扱う対象を 1 つに絞っているためにすぎません。

## 求心性「肥大」と呼んでいる理由

標準的な心エコーの分類では、

- RWT 上昇 ＋ **LV mass 正常** = concentric remodeling（求心性リモデリング）
- RWT 上昇 ＋ **LV mass 増加** = concentric hypertrophy（求心性肥大）

です。本モデルはこのステージで **心筋容積を約 78% 増加**させ（内腔は約 5% 縮小、
RWT は 0.36 → 0.57）、明確に後者を表現しています。したがって
**「求心性リモデリング」という名称は不適切**であり、`Concentric hypertrophy /
求心性肥大` としています。

なお、この判断は**変化の向き**（心筋量が増える）に基づくものです。
本モデルの絶対的な mass 値は臨床的な計測値ではありません（後述）。

## このモデルが表現していること

- **求心性リモデリング**：壁が厚くなり内腔は拡大せず、相対的壁厚（RWT）が上昇します。
- **遠心性リモデリング / 左室拡大**：内腔が拡大して細長い形から丸みを帯びた形へ変わり、
  大きくなった心腔に対して壁は相対的に薄くなります（RWT 低下）。心筋量は増加したままです。
- **収縮機能の低下**：1回拍出量が徐々に低下し、EF が低下します。
- **心拍出量**：本モデルでは安静時の心拍出量が比較的長く保たれ（約 4.7 L/min）、
  その後ゆるやかに低下します（約 4.3 L/min）。これは狙って置いた値ではなく、
  収縮性が落ちる一方で循環血液量と体血管抵抗が上がる、という入力の組み合わせから
  **計算結果として出てくる**ものです。
  EF が低下していても安静時心拍出量が比較的保たれる患者がいる、という一例を
  示したものです。**すべての HFrEF がこの推移をたどるわけではありません。**
  1回拍出量や心拍出量が病態進行に伴って必ず単調に低下する、とも主張していません。
- **充満圧の上昇**：左室拡張末期圧（LVEDP）・平均左房圧・平均肺静脈圧が
  上昇します（正常 state では LVEDP 7.2 / 平均左房圧 7.5 / 平均肺静脈圧
  9.9 mmHg、スライダー右端で 32.3 / 29.0 / 31.2 mmHg）。これも与えた値ではなく、
  拡張末期圧-容積関係（EDPVR）と循環全体の釣り合いの結果です。
- **収縮期の壁の肥厚**：心筋を非圧縮と仮定した幾何から自動的に出てきます。
  不全心では肥厚の程度が小さくなることも同時に表現されます。
- **肺うっ血**：後述。

## 肺うっ血の表現（最重要）

**肺うっ血は、血液が左室から肺へ逆向きに流れて戻る現象ではありません。**

```text
LV 充満圧 ↑ → 左房圧 ↑ → 肺静脈圧 ↑ → 肺毛細血管静水圧 ↑ → 間質・肺胞への水分貯留
```

したがって本モデルでは、**血流** と **圧の上昇** を視覚的に完全に分離しています。

- **血液粒子** は生理的な方向にしか動きません。
  拡張期：左房 → 僧帽弁 → 左室、収縮期：左室 → 大動脈弁 → 大動脈。
  大動脈を逆行する粒子はありません（駆出された粒子は退出時に消え、
  充満期に左房側からフェードインします）。
- **うっ血** は圧のレイヤーとして描いています。充満圧の上昇に伴って、
  左房 → 肺静脈 → 肺血管床 の順に **圧のフロント（グロー）が外向きに広がります**。
  伝わるのは圧であって血液ではありません。
- **間質の水分** は、血管の**外側**に配置した淡い粒子として、圧が高くなってから
  出現します。血液とは色・大きさ・動きをすべて変えてあります。

**どこから描き始めるかは、モデルが解いた圧で決まります。** 以前は進行度に紐づいた
0〜1 の指数でしたが、現在は平均肺静脈（肺毛細血管）圧 [mmHg] を臨床的な目安に
当てています。

| 圧（平均肺毛細血管・肺静脈圧） | 画面 |
| --- | --- |
| 〜12 mmHg | 何も出ません |
| 12 → 30 mmHg | 圧のフロントが左房 → 肺静脈 → 肺血管床へ広がります（圧に比例） |
| 22 → 32 mmHg | 間質の水分が現れ始めます（閾値的な立ち上がり） |

肺水腫が起きる圧には個人差が大きく、慢性心不全では急性期より高い圧に耐えます。
この 4 つの数値は**描画のための対応表であり、臨床的な閾値ではありません。**
とくに、**間質の水分量を圧から臨床的に定量化しているわけではありません**
——実際にどれだけ水分が間質へ移動するかは、血管透過性・膠質浸透圧・
リンパ排出に依存し、本モデルはそのいずれも持っていません。
この対応表が担っているのは「オーバーレイが、誰かが手で置いた数値ではなく
**モデルが解いた圧とともに増減する**」という一点だけです。
なお、間質の水分は state が示す量を超えて発生させません。

肺胞・リンパ管・Starling 力・間質性浮腫と肺胞性浮腫の区別は描いていません。

## 比較モード（正常 vs リモデリング後）

`Compare` ボタン（キーボード `C`）で、**正常な左室を横に並べて表示**します。

これは監査で最後まで残った弱点への対処です。1 本のスライダーという UI は、
どれだけ注記を書いても「次にこうなる」という順序を示唆します。正常な心臓を
横に置くことで、**順番ではなく「別の状態」として比較**できるようにしています。

- 比較用の心臓は、**同じモデルを progress = 0 で評価**して描いています。
  別途チューニングした絵ではないので、モデルと食い違うことがありません。
- 両者は**心周期の位相を揃えて**います。壁厚と内腔の比較を優先したためです。
  心拍数の差（例：70 → 82 /min）は数値パネル側に出しています。
- 比較モードでは血管と肺うっ血のレイヤーを非表示にします。
  比較の対象は心腔の形と駆出であり、周囲の構造は画面を混雑させるだけだからです。
- 数値パネルは「正常値 → 現在値」の形式になります
  （例：EF `58 → 19 %`、LVEDP `7 → 32 mmHg`、平均肺静脈圧 `10 → 31 mmHg`）。
- 圧-容積ループも 2 本並びます。正常心の小さく背の高いループと、
  不全心の大きく背の低いループ、そして傾きの違う 2 本の ESPVR が同時に見えます。
- 圧波形も重ねて表示され、駆出の始まる時刻と左房圧の高さの違いが読み取れます。

## 「残存血液」について

**収縮末期の残存血液（ESV）は正常心にも存在します。病的な血流うっ滞ではありません。**

粒子は大動脈弁からの距離でランク付けされているため、流出路に近い血液から駆出され、
心尖部側の血液が残ります。これは **アニメーション上の演出** であり、
EF が下がるほど「入れ替わりにくい血液が増える（washout の低下）」という
概念を示すためのものです。

- 心尖部血栓の形成を再現していません。
- 実際の心内血流のうっ滞を再現していません。
- 粒子の動きは **流体シミュレーション（CFD）ではありません。**

## 数理モデルの作り

### 循環モデル（time-varying elastance）

心臓の動きと表示される数値は、**閉じた循環の常微分方程式を解いた結果**です。
EDV・ESV・壁厚のキーフレーム表はもうありません。スライダーが動かすのは
**力学的なパラメータだけ**で、EF も 1回拍出量も充満圧も、そこから出てきます。

```text
スライダーが動かすもの（力学）        モデルが解くもの（結果）
Ees（収縮末期エラスタンス）           EDV / ESV / SV / EF
V0（無負荷容積）                  →   LVEDP・左房圧・肺静脈圧・肺動脈圧
EDPVR の硬さ（β）                     大動脈圧（収縮期 / 拡張期 / 平均）
体血管抵抗・循環血液量・心拍数         駆出のタイミング（等容性収縮期の長さ）
```

- **心室・心房の圧**：Suga–Sagawa の time-varying elastance。
  `P(V, t) = e(t)·Ees·(V − V0) + (1 − e(t))·A·(exp(β·(V − V0)) − 1)`
  収縮末期は線形（ESPVR）、拡張末期は非線形（EDPVR）です。
  活性化関数 `e(t)` は double-Hill 型で、心房は心室より遅れて収縮します。
- **区画**：左室・大動脈系・体静脈系・右室・肺動脈系・肺静脈（＋毛細血管）系・左房 の 7 つ。
  各区画の容積を状態変数とし、`dV/dt = 流入 − 流出` を RK4 で積分します。
  **どの瞬間でも 7 区画の総和は循環血液量に等しくなります**（テストで担保）。
- **弁**：理想的な一方向抵抗。上流圧 > 下流圧 のときだけ流れ、逆流はゼロです。
  等容性収縮期・等容性弛緩期は、この条件から自然に出てきます。
- **定常解**：1 拍ごとに EDV / ESV が前拍と 0.02 mL 以内に収まるまで積分を繰り返します。
  スライダーを動かすたびに解き直しますが、直前の解をウォームスタートに使い、
  結果をキャッシュしているため、1 回あたり数ミリ秒です。

**右心系と肺循環は、描いていませんが計算はしています。** ループが閉じていなければ、
左室が弱ったときに血液が肺静脈側に貯まる、という肺うっ血の機序そのものが
成立しないためです。

### 前負荷・後負荷スライダー

`Loading conditions` の 2 本は、**モデルの出力を上書きするものではなく、
入力を変えるもの**です。前負荷は循環血液量に、後負荷は体血管抵抗に掛かり、
循環全体が解き直されます。

- 前負荷を上げると EDV が増え、1回拍出量が増えます（Frank–Starling 機構）。
  同時に充満圧も上がります。「増やせば良い」わけではないことが同時に見えます。
- 後負荷を上げると 1回拍出量は減り、動脈圧は上がります。
  **その減り方は Ees の低い（＝不全）心のほうが大きくなります。** これは
  エラスタンスモデルから自然に出てくる性質で、どこにも書き込んでいません。

### 圧-容積ループ

左側のパネルは、解かれた 1 拍をそのまま P–V 平面に描いたものです。
点線は ESPVR と EDPVR、すなわち**その拍を生んだ式そのもの**です。
ループの左上隅が ESPVR に、右下隅が EDPVR に接するのは、当てはめた結果ではなく、
同じ方程式を積分した結果です。比較モードでは正常心のループも並べて表示します。

### 圧波形

その下のパネルは、**同じ 1 拍を容積ではなく時間に対して**描いたものです。
ループが「心室が何をしたか」を示すのに対し、こちらは「なぜそうなったか」を示します。

- 左室圧が大動脈圧の線を上向きに横切ったところで大動脈弁が開き、下向きに
  横切ったところで閉じます。**等容性収縮期・等容性弛緩期は、その交点と
  容積が動き始める／止まる時刻とのすき間**として見えます。
  影を付けた帯は、解かれた流量から求めた「大動脈弁が開いている区間」です。
  線が交わって見える場所ではなく、実際に流れている区間を塗っています。
- 左房圧を同じ軸に載せているのは、充満圧の上昇こそが肺うっ血オーバーレイの
  主題だからです。ここではそれがグローではなく 1 本の線として読めます。
  拡張期に左房圧が左室圧を上回っていることが、僧帽弁が開いている理由です。
- 横軸は「1 拍」であり、固定の秒数ではありません。比較モードでは 2 つの心臓の
  心拍数が違う（例：70 と 88 /min）ため、右端に両方の 1 拍の長さを
  「正常 → 現在」の形式で出しています。

**このシミュレーション上の HFrEF state では**、正常 state と比べて
**大動脈弁の開放が遅く**（＝駆出の帯の左側のすき間が広い）、
**左房圧の線が高い位置にあります**。どちらも書き込んだ挙動ではなく、
エラスタンスモデルから出てくる帰結です。

ただしこれは **「HFrEF では等容性収縮期が延長する」という一般則ではありません。**
実際の等容性収縮時間は心拍数・前後負荷・伝導・収縮予備能などでも動き、
本モデルはそのうち一部しか変化させていません。ここで言えるのは
「この 2 つの simulated state を比べるとそうなる」ということだけです。

### 左房圧波形について

左房圧のトレースには **v 波（心室収縮期に、閉じた僧帽弁に対して肺静脈から
左房が充満する）** と **a 波（心房収縮）** が出ます。正常 state での値:

| | 圧 | 位相 |
| --- | --: | --- |
| v 波 | 12.1 mmHg | 0.50（駆出終了の直後） |
| a 波 | 8.0 mmHg | 0.89（拡張後期） |
| 谷 | 4.8 mmHg | 0.65 |
| 平均左房圧 | 7.5 mmHg | — |

**どちらの波が高いかは、モデルの要件にしていません。** 実際の左房では v 波の
ほうが高いことが多いのですが、その大小は心拍数・心房収縮性・負荷条件でも動き、
本モデルが保証できる性質ではないためです。テストで確認しているのは
「両方の波が実際の振れとして存在すること」「v 波が a 波より前に来ること」
「v 波が駆出中〜直後にピークを取ること（＝その機序どおりの位置にあること）」
の 3 点です。

これは監査で見つけた不具合の修正でもあります。以前の左房は EDPVR の係数
（`edpvrA` = 0.35）が小さく、左房が実際に動く容積範囲で **受動項が 1〜3 mmHg
しか出ていませんでした**。圧のほとんどが心房収縮の項からしか出ないため、
**v 波がほぼ立たず、a 波だけが目立ち、平均左房圧が左室拡張末期圧より
数 mmHg 低いまま**になり、肺循環側が左室から実質的に切り離されていました。
係数を 2.0 に上げ、同じ容積範囲で受動項が概ね 4〜12 mmHg 出るようにしています。

> **これらは本モデルの較正パラメータであり、計測値ではありません。**
> この関係式の局所的な傾き（mL/mmHg）を臨床的な左房コンプライアンスの計測値と
> 同一視しないでください。7 区画の集中定数ループのうち 1 区画が妥当な圧を出す
> ように当てはめた 1 本の指数関数にすぎず、心房壁の力学・粘弾性・
> reservoir / conduit / pump の分解などは背後にありません。

**再現していないもの:**

- **x 谷・y 谷の細部**：谷は 1 つの滑らかな下降として出るだけで、
  x 谷と y 谷を区別できる形にはなっていません。
- **c 波**：僧帽弁の膨隆に対応する成分は含みません。
- **dicrotic notch（重複切痕）**：集中定数モデルのため大動脈圧波形には出ません。
- **圧の絶対値の臨床的読み替え**：模式的な値であり、
  カテーテル計測値として読むものではありません。

### 心筋の非圧縮性（2 階層）

幾何のほうは引き続き **2 階層モデル** です。心筋を非圧縮として扱う仮定は
「1 心拍の中」でのみ有効で、病態ステージ間では心筋量そのものが変化してよいためです。

```text
病態ステージ
  → 拡張末期の内腔容積（循環モデルが解いた値） + 拡張末期の壁厚
  → そのステージの心筋容積            ← ステージ間では変化する
  → 1 心拍の間は一定                  ← 非圧縮の仮定はここだけ
  → 収縮期の壁肥厚が幾何から自然に出る
```

内腔は回転楕円体（長軸/短軸比 `longToShortAxisRatio`）として近似しています。
この比は臨床の sphericity index と同じ向きに動きますが、
**臨床計測値ではなく本モデルの形状パラメータ** です。

画面の形、圧-容積ループ、圧波形、そして右側の数値
（EF / EDV / ESV / SV / HR / CO / LVEDP / 肺静脈圧 / 動脈圧 / 壁厚）は、
**すべて同じ解から導かれています**。

## UI に出していない数値

- **左室心筋重量**：内部では計算していますが表示しません（心筋密度 1.05 g/mL を明示）。
  **この値は幾何学的な整合性のために内部で用いているだけで、臨床の心エコーによる
  LV mass 計測値ではありません。** 切断楕円体近似から得られる値であり、
  臨床的な正常範囲との比較にも使えません（LV mass の基準値自体、性別・体格・
  計測法・indexing に依存します）。本モデルで意味があるのは絶対値ではなく、
  **ステージ間で心筋量が増加するという向き** だけです。
圧については逆に、**mmHg の数値を出すようになりました。** 以前は「やや上昇 / 上昇」
といった定性表示にしていましたが、これは根拠のある圧を計算できなかったためです。
現在の圧は循環モデルが解いた値なので、単位付きで表示しています。ただし
**表示は 1 mmHg 刻み**で、それ以上の桁は出しません（集中定数モデルの精度を超えるため）。

## このモデルが表現していないこと

- **HFpEF（駆出率が保たれた心不全）**：扱っていません。
  なお肺うっ血は HFrEF に特異的ではなく、HFpEF でも生じます。
- **右心系・肺循環・体循環の「描画」**：計算はしていますが、画面に描いているのは
  左室・左房・大動脈起始部・肺静脈だけです。右室不全・肺高血圧そのものを
  主題にしたシーンではありません。
- **集中定数モデルであること**：区画は 1 つあたり 1 つの圧しか持たず、血管の慣性
  （inertance）・波動伝播・分布定数的な性質は含みません。したがって圧波形の細部
  （dicrotic notch など）は再現されません。肺静脈区画は毛細血管床を含めて 1 つに
  まとめてあり、その圧を間質への水分移動の駆動圧として扱っています。
  心房収縮期には肺静脈側へ血液がわずかに押し戻されます（実際にも肺静脈血流の
  心房逆行波として観察されます）が、集中定数近似のため実際よりやや大きめに出ます。
- **弁の動き**：弁は理想的な一方向抵抗として計算しており、弁輪はリング状の目印で
  開閉しません。逆流（僧帽弁閉鎖不全・大動脈弁閉鎖不全）や狭窄も含みません。
- **原因疾患**：虚血性・弁膜症性・高血圧性・心筋症などの違いは描いていません。
- **神経体液性因子**：RAA 系・交感神経系の活性化は描いていません。
  心拍数の上昇のみをキーフレーム値として与えています。
- **治療の影響**：薬物・デバイスによる逆リモデリングは含みません。
- **形態**：右室は外形のみの文脈的な膨らみで、右室腔・右室機能・
  心室間相互作用は含みません（後述）。乳頭筋・腱索・弁尖は**模式的に**
  描いています（後述）——弁の力学は計算していません。

## 3D 形状・質感の解剖学的シェーピングについて

チャンバーの 3D 形状は、循環モデルが解いた **内腔容積・心筋容積・長短軸比** を
唯一のスケールとして、その上に固定の「形の場」を重ねて描いています
（`geometry/ventricleGeometry.js`）。重要なのは、これらがすべて
**再配分であって増減ではない**ことです：

- **壁厚の場**（心尖部で薄く、中隔で厚い）は平均が約 1 になるよう設計し、
  解かれた心筋容積を保ったまま分布だけを変えます。描かれた壁厚が解かれた
  壁厚を数 % 以内で追随することはテストで担保しています
  （`tests/chamber-geometry.test.js`）。
- **中隔側の扁平化・心尖の側方偏位・表面の微小な凹凸**は視覚的な
  もっともらしさのための形状パラメータで、いかなる計測値でもありません。
- **右室の膨らみ**は文脈的な目印にすぎません。右室腔はなく、拍動も左室外形に
  従うだけです。右心系の力学は（計算はしていても）描画していません。
- **心尖固定と弁輪降下**：収縮は base→apex の向きで描き、心尖はほぼ固定、
  弁輪（僧帽弁・大動脈弁のリング）が心尖方向へ降下します。長軸短縮の量は
  解かれた容積変化から出ますが、**どこを固定点にするか**は表示上の選択です
  （`APEX_PINNING`）。
- **捻れ（torsion）**：心尖が基部に対して回旋する動きを、駆出の進行 ×
  EF に比例した **例示的な振幅** で加えています（`TORSION_ILLUSTRATIVE_MAX`）。
  実際の捻れは HFrEF で低下する、という**向き**だけを表現したもので、
  角度は計測値ではありません。本モデルは捻れを解いていません。
- **切断面の線維感・心外膜の冠動脈様のテクスチャ**は手続き的な質感であり、
  実際の線維走行・冠動脈解剖を表しません。
- **乳頭筋・腱索・僧帽弁尖・大動脈弁尖**は模式表現です。乳頭筋は前外側・
  後内側の 2 群のみで、腱索は代表的な数本、弁尖は前尖・後尖（僧帽弁）と
  3 尖（大動脈弁）の簡略膜です。**開閉のタイミングだけ**が本物です——
  循環モデルが解いた弁の開閉位相（駆出の開始・終了、充満）に従って
  動きます。弁の力学・逆流・狭窄・腱索張力はモデルにありません。
- **肉柱（trabeculae carneae）**は心尖部〜中位の内腔面の起伏として
  模式的に描き、流出路は滑らかにしています。実際の肉柱解剖の再現では
  ありません。
- **肺静脈は 4 本**（左右 2 本ずつ）を模式的に描き、その先の分枝は
  「肺血管側へ続く」ことを示す簡略表現です。肺の解剖は描いていません。
  うっ血時の静脈拡張（engorgement）・暗色化は圧上昇に伴う変化の模式表現で、
  拡張の量は計測値ではありません。

## 数値について

表示される EF・EDV・ESV・SV・CO・LVEDP・肺静脈圧・動脈圧は、
**循環モデルを解いた結果**であり、表に書かれた値ではありません。
一方、その入力となる力学パラメータ（Ees・V0・EDPVR の硬さ・体血管抵抗・
循環血液量・心拍数・壁厚）は、各パターンの教科書的な代表例を意識して選んだ
**一例**です。実際の症例では大きくばらつきます。

計算結果がモデルとして一貫していることと、臨床的に代表的であることは別の話です。
既知のずれとして、本モデルの平均動脈圧はスライダー全域で概ね 95〜110 mmHg に
とどまります（心拍出量の低下が緩やかな一方で体血管抵抗が上がるため、モデル内部
では整合しています）。実際の HFrEF の経過では、これより血圧が下がる例が
少なくありません。

**EF の値だけで心不全の重症度は判断できません。**

## The end-diastolic outline

In the comparison, and during the two beat steps of the guided sequence, a thin
cage marks where the endocardial surface sat at end-diastole. It is drawn from
`ventricleShape()` evaluated at the state's own `edvMl` — the same function that
draws the beating chamber, at a different volume. Nothing about it is hand-drawn,
and it carries no value the model does not already produce.

It is drawn as lines rather than as a surface so that it cannot be read as
tissue: it is a measurement mark, and the gap between it and the moving lining is
the stroke. Its opacity follows how far through the stroke the cavity currently
is, so at end-diastole (where it lies exactly on the lining) it is not drawn at
all.

What it is **not**: it is not an imaging measurement, not a wall-motion score,
and the gap is not a quantified stroke volume. It is there so that "this
ventricle empties less" is something the viewer sees rather than reads.

## すべての prototype に共通して表現していないこと

- **形状は解剖学的に検証されていません。** 各臓器は「その臓器だと分かる」
  シルエットの特徴（肺の心切痕、腎の腎門、大腸のハウストラ、長管骨の骨幹端など）
  を選んで作った stylized model です。**寸法・比率・位置関係は概略**であり、
  計測には使えません。
- **数値を一切出していません。** 進行度スライダーは「呼吸の深さ」「運動パターン」
  「刺激の強さ」「周期上の位置」などの**相対的な軸**であり、
  mL・mmHg・mm・分などの単位を持ちません。重症度スケールでもありません。
- **動きの速さは説明のための値です。** 呼吸数・蠕動の周期・粒子の速度は
  見て分かることを優先した presentation 値で、生理学的な計測値ではありません
  （コード上も `speed` / `rate` / `phase` など演出値と分かる名前にしてあります）。
- **粒子は「向きと勢い」の表現であって流量ではありません。** 圧から速度を
  解いてはいません。粒子の数・密度は、細胞数・分子数・血球数のいずれでもありません。
- **半透明表示は演出です。** 肝臓・膵臓・甲状腺・脾臓・腎臓・膀胱を透かして
  いるのは内部の流れや構造を見せるためで、組織の性質ではありません。
- **顕微構造を描いていません。** 肺胞・ネフロン・肝小葉・膵腺房・濾胞上皮・
  骨梁・筋節はいずれも構造として描いていません。膵島・甲状腺濾胞は
  「そこに何かがある」ことを示す模式的な球です。
- **神経支配・ホルモン制御・自律神経の調節を描いていません。**
