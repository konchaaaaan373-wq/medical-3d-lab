# 医学的な表現について / Medical notes

共通の原則:

- どのテーマも **教育目的の簡易モデル** であり、症例の計測値でも
  シミュレーションでもありません。画面上に常時その注記を表示しています。
- 数値を出す場合は、教科書的な代表値の「変化の方向」を示すためのものであり、
  個々の患者の予測ではありません。
- 断定的な因果の主張は避け、「〜と考えられています」「〜のひとつです」といった
  表現を用いています。
- 文言はすべて `src/data/<theme>.js` に集約してあり、監修者のレビューは
  そのファイルだけを見れば反映できます。

# アミロイドβの蓄積

## このモデルが表現していること

「**Aβ が増える → 集まる → 線維になる → プラークになる**」という
凝集カスケードの **概念** を、視覚的に理解しやすい形で示すことだけを目的にしています。

- Aβ は健常な脳でも産生・分解されており、正常状態でも少量が存在します
  （進行度 0% でも粒子がゼロにならないのはこのためです）。
- 産生と排出（クリアランス）のバランスが崩れると、可溶性 Aβ が蓄積すると考えられています。
- 可溶性オリゴマーはシナプス機能障害との関連が広く議論されている分子種です。
- 線維は β シート構造をとり、末端に Aβ が付加されることで伸長します。
- プラーク（老人斑）は **細胞外** の沈着物です。本モデルでも、
  すべての凝集体は細胞の外側にのみ配置しています。

## このモデルが表現していないこと

以下は意図的に省略・単純化しています。**実際とは異なります。**

- **スケール**：粒子・線維・プラーク・神経細胞の相対的な大きさは正確ではありません。
- **数**：粒子数は見やすさで決めた値で、実際の分子数とは無関係です。
- **時間**：スライダーの 0→100% は数十年単位の経過を数十秒に圧縮した概念的なものです。
  一定速度で進行することを意味しません。
- **分子構造**：Aβ40 / Aβ42 の違い、APP の切断過程、βセクレターゼ・γセクレターゼ、
  ApoE などの因子は登場しません。
- **タウ病理・神経炎症**：神経原線維変化、ミクログリア、アストロサイトの反応は
  含まれていません。アルツハイマー病の病理はアミロイドだけでは説明できません。
- **因果関係**：本モデルは「Aβ の蓄積が認知症を引き起こす」と主張するものではありません。
  アミロイドカスケード仮説をめぐる議論には立ち入っていません。

## 表現上のルール

- 神経細胞は進行に伴ってわずかに減光し、樹状突起スパインが小さくなります。
  これは「Aβ 病理とシナプスの変化に関連があると考えられている」ことの
  **模式的な示唆** であり、細胞死を描いたものではありません。
  断定的なラベルは付けていません。
- 解説文では「〜と考えられています」「〜のひとつです」といった表現を用い、
  不必要に断定的にならないようにしています。
- 画面上には常に「教育目的の簡易モデルです」という注記を表示しています。
  UI を非表示にしてキャプチャする場合は、投稿側で同等の注記を添えてください。

## 文言を修正したいとき

ステージ名・解説文・注記はすべて `src/data/amyloidBeta.js` にまとまっています。
描画コードを触らずに編集できます。監修者のレビューを反映する場合はこのファイルを見てください。

# 心不全（左室リモデリング）

## このモデルが表現していること

- 左室を**切り欠いた模式図**として描き、**壁の厚さ**と**内腔の大きさ**の関係が
  進行に伴ってどう変わるかを示します。
- 代償期には壁が厚くなり（求心性肥大）、心拍出量がしばらく保たれること。
- リモデリングが進むと内腔が拡大し、**球形に近づく**こと（sphericity の上昇）。
  これは予後不良のマーカーとして知られる変化です。
- 大きくなった心腔に対して壁が相対的に薄くなること（relative wall thickness の低下）。
- 1 回の収縮で駆出しきれない血液（残存血液）が増え、**EF が低下**すること。
  残る血液が心尖部側に偏るのは、左室内の血流うっ滞の模式的な表現です。
- 駆出しきれない血液が上流（左房・肺静脈・肺血管床）に滞ること。

## モデルの作り

- 心筋は**非圧縮**として扱い、心筋の体積を一定に保ったまま外径を解いています。
  そのため**収縮期の壁の肥厚**は、手でアニメーションを付けたものではなく
  モデルから自然に出てきます。
- 内腔は回転楕円体として近似し、体積 → 半径を計算しています。
  画面の形と右側の数値（EF / EDV / ESV / 1回拍出量 / 壁厚）は同じ計算から
  出ているため、**絵と数字が食い違いません**。
- 各ステージの EDV / ESV / 壁厚 / 心拍数は `src/data/heartFailure.js` の
  キーフレームに置いてあり、そこを書き換えるだけで挙動が変わります。

## このモデルが表現していないこと

- **右心系・肺循環・体循環**：描いているのは左室・左房・大動脈起始部・肺静脈だけです。
  体循環は画面外にあり、駆出された血液はフェードアウトして消えます。
- **収縮能と拡張能の区別**：本モデルは HFrEF（駆出率の低下した心不全）の
  経過を単純化したものです。**HFpEF（駆出率が保たれた心不全）は扱っていません。**
- **原因**：虚血性・弁膜症性・高血圧性・心筋症など、原因による違いは描いていません。
- **神経体液性因子**：RAA 系・交感神経系の活性化、リモデリングの分子機構は含みません。
  心拍数の上昇だけを、代償の一端として簡略に示しています。
- **治療の影響**：薬物治療やデバイス治療による逆リモデリングは含みません。
- **弁の動き・血流の物理**：弁輪はリング状の目印で、開閉はしません。
  血液粒子は流体シミュレーションではなく、経路に沿って動かしているだけです。
- **形態**：左室を回転体として近似しているため、実際の心臓の形（右室との関係、
  心筋線維の走行、乳頭筋・腱索）は描いていません。

## 数値について

表示される EF・EDV・ESV・壁厚・心拍数は、各段階の教科書的な代表値を
なめらかにつないだものです。実際の症例では大きくばらつきます。
特に **EF の値だけで重症度を判断することはできません**。
